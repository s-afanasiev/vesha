## РАЗДЕЛ 1. Категориальный глоссарий и онтология домена

| Физическая / Математическая сущность | Вычислительный эквивалент | Входные и выходные типы данных | Инвариант / Контракт |
| :--- | :--- | :--- | :--- |
| **Конфигурационное пространство** ($M$) | Абстрактный топологический тип данных (Многообразие) | $\text{Void} \to M$ | Задает геометрическое множество допустимых конфигураций системы без привязки к координатной сетке. $dim(M) = n$. |
| **Обобщенные координаты** ($q, \chi$) | Координатный адаптер (Координатная карта) | $\chi: M \to \mathbb{R}^n$ | Локальный диффеоморфизм. Гарантирует взаимно однозначное гладкое отображение между точками многообразия и вещественным вектором размерности $n$. |
| **Координатная траектория** ($q(t)$) | Функциональный объект (Time-Parameterized Path) | $t: \mathbb{R} \to \mathbb{R}^n$ | Непрерывная дифференцируемая функция времени класса $C^k$ ($k \ge 2$). |
| **Обобщенная скорость** ($Dq(t)$) | Производный функциональный поток | $D: (\mathbb{R} \to \mathbb{R}^n) \to (\mathbb{R} \to \mathbb{R}^n)$ | $Dq(t) = \lim_{\Delta t \to 0} \frac{q(t+\Delta t) - q(t)}{\Delta t}$. Скорость является атрибутом траектории, а не изолированной точки конфигурации. |
| **Оператор лифтинга локального кортежа** ($\Gamma$) | Структурный лифтинг-оператор высшего порядка (Path-to-Bundle Lifter) | $\Gamma: (\mathbb{R} \to \mathbb{R}^n) \to (\mathbb{R} \to \text{Tuple})$ | $\Gamma[q](t) = (t, q(t), Dq(t), \dots, D^k q(t))$. Разворачивает временную траекторию в локальный срез касательного расслоения $TM$. |
| **Локальный кортеж состояния** ($\text{Local State Tuple}$) | Неизменяемый объект-значение (Immutable Value Object / Struct) | $\text{Tuple} = \langle t: \mathbb{R}, q: \mathbb{R}^n, v: \mathbb{R}^n, \dots \rangle$ | Позиционная независимость аргументов. Значения $t, q, v$ ортогональны и рассматриваются как свободные формальные параметры функции. |
| **Оператор соприкосновения** ($O$ / Osculating Path) | Фабрика локальной аппроксимации пути | $O: \text{Tuple} \to (\mathbb{R} \to \mathbb{R}^n)$ | Для кортежа $(t, q, v, a)$ строит траекторию $q'(t') = q + v(t'-t) + \frac{1}{2}a(t'-t)^2 + \dots$, имеющую заданный порядок касания с истинной траекторией. |
| **Оператор абстрагирования кортежа** ($\bar{\Gamma}$) | Инвертор функциональной зависимости | $\bar{\Gamma}: ((\mathbb{R} \to \mathbb{R}^n) \to (\mathbb{R} \to Y)) \to (\text{Tuple} \to Y)$ | $\bar{\Gamma}(\bar{f})(t, q, v) = \bar{f}[O(t, q, v)](t)$. Превращает функционал траектории в чистую функцию локального кортежа. |
| **Лагранжиан** ($L$) | Чистый функциональный интерфейс оценки состояния (Cost Kernel) | $L: \text{Tuple} \to \mathbb{R}$ | Скалярная функция. Зависит от конечного префикса локального кортежа. Принимает свободные формальные параметры: $L(t, q, v) = T(t, q, v) - V(t, q)$. |
| **Действие Лагранжа** ($S[q]$) | Глобальный функционал стоимости (Objective / Path Cost Functional) | $S: (\mathbb{R} \to \mathbb{R}^n) \times \mathbb{R} \times \mathbb{R} \to \mathbb{R}$ | $S[q](t_1, t_2) = \int_{t_1}^{t_2} (L \circ \Gamma[q])(t) dt$. Аддитивность по времени. Стационарность на физически реализуемых траекториях ($\delta S = 0$). |
| **Оператор Эйлера–Лагранжа** ($E[L]$) | Оператор дифференциальной невязки (Residual Evaluator) | $E: (\text{Tuple} \to \mathbb{R}) \to (\text{Tuple} \to \mathbb{R}^n)$ | $E[L] = D_t(\partial_2 L) - \partial_1 L$. На истинной траектории невязка тождественно равна нулю: $(E[L] \circ \Gamma[q])(t) = 0$. |
| **Полная производная по времени** ($D_t$) | Инфинитезимальный оператор сдвига состояния | $D_t: (\text{Tuple} \to Y) \to (\text{Tuple} \to Y)$ | $D_t F = \partial_0 F + (\partial_1 F)v + (\partial_2 F)a + \dots$ Коммутирует с оператором проекции вдоль траектории: $D_t F \circ \Gamma[q] = D(F \circ \Gamma[q])$. |
| **Обобщенный импульс** ($p$) | Ковекторная функция состояния (Conjugate Momentum) | $\mathcal{P}: \text{Tuple} \to (\mathbb{R}^n)^*$ | $p = \partial_2 L(t, q, v)$. Сопряженная переменная в пространстве кокасательного расслоения $T^*M$. |
| **Преобразование Лежандра** | Алгебраический дуальный инвертор (Fenchel–Legendre Transform) | $\mathcal{F}L: (\text{Tuple}_{TM} \to \mathbb{R}) \to (\text{Tuple}_{T^*M} \to \mathbb{R})$ | Замена активного аргумента $v \mapsto p$ через обращение $\partial_2 L$. $H(t, q, p) = p \cdot v(t, q, p) - L(t, q, v(t, q, p))$. Инволютивно: $(\mathcal{F}L)^{-1} = \mathcal{F}H$. |
| **Фазовое пространство** | Кокасательное расслоение $T^*M$ | $\text{Void} \to T^*M$ | Четномерное многообразие размерности $2n$. Элементы — кортежи $(t, q, p)$. |
| **Гамильтониан** ($H$) | Генератор фазового потока / Функция энергии | $H: \text{Tuple}_{T^*M} \to \mathbb{R}$ | Полная энергия в координатах $(t, q, p)$. Порождает симплектический фазовый поток. |
| **Уравнения Гамильтона** | Векторное поле фазового потока (Phase State Derivative) | $\text{Tuple}_{T^*M} \to \text{Tuple}_{T^*M}$ | $\dot{q} = \partial_2 H(t, q, p)$, $\dot{p} = -\partial_1 H(t, q, p)$. Система ОДУ 1-го порядка, разрешенная относительно производных. |
| **Симплектическая единица** ($J_n$) | Канонический структурный тензор / Матрица косой симметрии | $\mathbb{R}^{2n \times 2n}$ | $J_n = \begin{pmatrix} 0 & I_n \\ -I_n & 0 \end{pmatrix}$. $J_n^T = -J_n = J_n^{-1}$. Задает симплектическую геометрию фазового пространства. |
| **Скобка Пуассона** ($\{F, G\}$) | Билинейный кососимметричный дифференциальный оператор (Алгебра Ли) | $\{F, G\}: (T^*M \to \mathbb{R}) \times (T^*M \to \mathbb{R}) \to (T^*M \to \mathbb{R})$ | $\{F, G\} = \partial_1 F \partial_2 G - \partial_2 F \partial_1 G = (DF) J_n (DG)^T$. Удовлетворяет тождеству Якоби: $\{F, \{G, H\}\} + \text{cycl.} = 0$. |
| **Каноническое преобразование** ($C_H$) | Симплектический автоморфизм фазового пространства | $C_H: T^*M \to T^*M$ | Сохраняет форму уравнений Гамильтона. Матрица Якоби удовлетворяет: $M J_n M^T = J_n$. Сохраняет фазовый объем и скобки Пуассона. |
| **Симплектическая 2-форма** ($\omega$) | Билинейная дифференциальная форма инкрементов | $\omega: \Delta(T^*M) \times \Delta(T^*M) \to \mathbb{R}$ | $\omega(\zeta_1, \zeta_2) = \zeta_1^T J_n \zeta_2 = P(\zeta_2)Q(\zeta_1) - P(\zeta_1)Q(\zeta_2)$. Абсолютный инвариант канонических преобразований. |
| **Теорема Лиувилля** | Инвариант сохранения плотности фазового потока | $\text{div}(X_H) = 0 \implies \text{vol}(C_H(R)) = \text{vol}(R)$ | Якобиан фазового потока $\det(\text{Jac}(g_{\Delta t})) = 1$. Исключает появление аттракторов в замкнутых консервативных системах. |
| **Производящая функция** ($F_1, F_2, F_3, F_4$) | Алгебраический генератор канонического адаптера | $F_2: (t, q, p') \to \mathbb{R}$ | $p = \partial_1 F_2$, $q' = \partial_2 F_2$, $H' = H + \partial_0 F_2$. Неявная спецификация взаимосвязи старого и нового базисов. |
| **Преобразование Ли** ($e^{\epsilon L_W}$) | Однопараметрическая группа канонических сдвигов | $L_W F = \{F, W\} \implies E_{\epsilon, W} F = e^{\epsilon L_W} F$ | Генерирует явное каноническое преобразование по заданному гамильтонову генератору $W$. Не требует обращения матриц. |
| **Интеграл Нётер** ($\mathcal{I}$) | Неизменяемый инвариант бизнес-логики | $\mathcal{I}: \text{Tuple} \to \mathbb{R}$ | $\mathcal{I} = (\partial_2 L)(D\tilde{F}(0))$. Если система инвариантна относительно группы Ли преобразований $\tilde{F}(s)$, то $D_t \mathcal{I} = 0$. |
| **Связи** (Голономные) | Алгебраический фильтр / Снижение размерности | $\phi(t, q) = 0$ | Снижает число степеней свободы: $dim(Q) = 3N - k$. Исключаются подстановкой обобщенных координат до вычисления динамики. |
| **Связи** (Неголономные) | Дифференциальный проектор скоростей | $\psi(t, q, v) = G_1(t, q)v + G_2(t, q) = 0$ | Не сводятся к координатным. Не выводятся из принципа наименьшего действия; требуют проекции по Д'Аламберу–Лагранжу. |
| **Сечение Пуанкаре** | Стробоскопический редуктор непрерывного потока в дискретное отображение | $P: \Sigma \to \Sigma$ ($\Sigma \subset T^*M$, $\dim(\Sigma) = 2n-2$) | Сохраняет площадь (симплектичность). Разделяет фазовое пространство на регулярные торы, резонансные островки и хаотическое море. |

## РАЗДЕЛ 2. Свод базовых архитектурных правил (Регламент)

### Rule 1. Изоляция истинной геометрии от координатных систем (Coordinate-Free Independence)
1.1. Любая динамическая сущность обладает объективной инвариантной геометрией (положением, распределением масс, кинематическими связями), не зависящей от выбора численного базиса представления.  
1.2. Обобщенные координаты $q$ являются внешними проекционными адаптерами ($\chi: M \to \mathbb{R}^n$), а не внутренними свойствами модели.  
1.3. Лагранжиан и функционал действия должны вычисляться так, чтобы уравнения движения, полученные в координатах $q$ и $q'$, порождали эквивалентные траектории на многообразии: $L' = L \circ C$, где $C$ — расширенное преобразование локального кортежа.  
1.4. Запрещается зашивать семантику декартова пространства в универсальные вычислительные модули динамики.

### Rule 2. Природа динамического состояния: состояние как локальный функциональный срез
2.1. Динамическое состояние в конфигурационном подходе не является скаляром или изолированным вектором значений. Состояние системы в момент времени $t$ строго определяется локальным кортежем:
$$\Gamma[q](t) = (t, q(t), Dq(t), D^2 q(t), \dots)$$
2.2. Лагранжиан $L$ обязан быть чистой функцией локального кортежа $L(t, q, v)$. Запрещается неявное обращение к глобальному времени или скрытым переменным состояния внутри функции $L$.  
2.3. Взятие частных производных лагранжиана $\partial_0 L, \partial_1 L, \partial_2 L$ производится строго структурно по позициям кортежа *до* подстановки траектории движения:
$$E[L][q] = D(\partial_2 L \circ \Gamma[q]) - \partial_1 L \circ \Gamma[q] = 0$$
Никакие подстановки переменных $v = \dot{q}(t)$ не допускаются до завершения вычисления производной оператора.

### Rule 3. Принцип экстремали действия как универсальный валидатор и генератор путей
3.1. Реализуемое поведение системы выделяется из множества всех геометрически допустимых путей требованием стационарности интегрального функционала действия $S[q](t_1, t_2) = \int_{t_1}^{t_2} L(\Gamma[q](t)) dt$.  
3.2. Допустимыми вариациями $\eta(t)$ пути $q(t)$ являются гладкие возмущения, исчезающие на границах интервала: $\eta(t_1) = \eta(t_2) = 0$.  
3.3. Если две функции лагранжиана $L$ и $L'$ отличаются на полную производную по времени от произвольной функции координат и времени ($L' = L + D_t F(t, q)$), они строго эквивалентны: $\delta S = \delta S'$, уравнения движения тождественны. Архитектура должна допускать калибровочное преобразование функции стоимости без искажения доменного поведения.

### Rule 4. Разграничение Лагранжева и Гамильтонова подходов к мутации и хранению состояния
4.1. **Лагранжев подход (Конфигурационный):**
- Состояние: $(t, q, v) \in TM$ (касательное расслоение).
- Уравнения движения: система дифференциальных уравнений второго порядка: $D^2 q = A(t, q, Dq)$.
- Разрешение относительно старшей производной требует обращения матрицы $\partial_2 \partial_2 L$.
- Применение: естественная композиция связанных систем, моделирование наложения механических связей.
4.2. **Гамильтонов подход (Фазовый):**
- Состояние: $(t, q, p) \in T^*M$ (кокасательное расслоение).
- Уравнения движения: каноническая система ОДУ первого порядка: $\dot{q} = \partial_2 H$, $\dot{p} = -\partial_1 H$.
- Применение: численная эволюция во времени, симплектическое интегрирование, обнаружение скрытых симметрий, анализ хаоса и резонансов.
4.3. Переход между подходами выполняется исключительно через преобразование Лежандра $\mathcal{F}L$ по аргументу скорости. Запрещается смешивать переменные скорости $v$ и импульса $p$ в одном интерфейсе состояния без явного адаптера Лежандра.

### Rule 5. Закон сохранения как прямое следствие симметрии (Теорема Нётер)
5.1. Если доменная функция лагранжиана инвариантна относительно непрерывной однопараметрической группы преобразований координат $\tilde{F}(s)$:
$$L \circ \tilde{C}(s) = L \quad \forall s$$
то система обязана гарантировать сохранение соответствующего инварианта бизнес-логики (интеграла движения):
$$\mathcal{I}(t, q, v) = (\partial_2 L)(D\tilde{F}(0)) = \text{const}$$
5.2. Если координата $q^i$ является циклической ($\partial_1 L)_i = 0$, сопряженный импульс $p_i = (\partial_2 L)_i$ является строгим инвариантом времени.  
5.3. Архитектура домена обязана использовать циклические координаты для автоматической редукции размерности решаемой задачи (Routhian / Phase space reduction).

### Rule 6. Управление связями: голономная редукция vs множители Лагранжа
6.1. Голономные связи $f(t, q) = 0$ обязаны устраняться на этапе спецификации системы путем построения параметрического базиса минимальной размерности ($q = F(t, q_{\text{min}})$).  
6.2. В случае составных систем с модульными связями разрешается использовать избыточные координаты с расширенным лагранжианом:
$$L_{\text{ext}}(t; q, \lambda; \dot{q}, \dot{\lambda}) = L(t, q, \dot{q}) + \lambda \cdot \phi(t, q)$$
при условии, что множители $\lambda$ (силы реакции связей) вычисляются как зависимости от локального состояния и исключаются из результирующей эволюции.  
6.3. Неголономные связи $\psi(t, q, v) = 0$, не являющиеся полными производными по времени, запрещено моделировать через наивный вариационный принцип; они требуют проекции по принципу Д'Аламбера–Лагранжа.

### Rule 7. Симплектическая инвариантность и теорема Лиувилля
7.1. Эволюция фазового состояния во времени $g_{\Delta t}: (q(t), p(t)) \mapsto (q(t+\Delta t), p(t+\Delta t))$ является каноническим (симплектическим) преобразованием.  
7.2. Фазовый поток консервативной системы обязан сохранять ориентированный фазовый объем (теорема Лиувилля): $\det(\text{Jac}(g_{\Delta t})) = 1$.  
7.3. В архитектуре консервативных систем категорически запрещается использование несимплектических численных методов интегрирования (например, наивного метода Эйлера), так как они вносят искусственную диссипацию или накапливают фиктивную энергию.

## РАЗДЕЛ 3. Паттерны проектирования и ООП-парадигмы в механике

### 1. Паттерн «Локальный срез состояния» (Local State Bundle / Value Object)
- **Контекст:** Эволюция системы второго порядка требует для определения будущего не только координат, но и скоростей (и производных более высокого порядка). Традиционная попытка хранить скорость как внутреннюю мутацию объекта координаты приводит к состоянию гонки и временной связанности.
- **Архитектурное решение:** 
  - Состояние моделируется как неизменяемый Value Object `LocalStateTuple`, инкапсулирующий кортеж $\langle t, q, v, \dots \rangle$.
  - Координаты $q$ и обобщенные скорости $v$ трактуются как независимые формальные аргументы. Связь между $q$ и $v$ восстанавливается только оператором траектории $\Gamma[q]$.
  - Для вычисления производных по состоянию используется оператор соприкасающегося пути (`OsculatingPath`), который преобразует мгновенный срез в локальный степенной ряд.
- **Типовой контракт:**
```typescript
interface LocalState<Q, V> {
  readonly time: number;
  readonly coordinates: Q;
  readonly velocities: V;
}

interface StateDerivative<Q, V, A> {
  readonly timeRate: 1;
  readonly coordinateRate: V;
  readonly velocityRate: A;
}
```

### 2. Паттерн «Функциональное ядро Лагранжа» (Functional Core / Objective Evaluation)
- **Контекст:** Оценка энергетического состояния и законов динамики должна быть изолирована от механизма численного решения дифференциальных уравнений.
- **Архитектурное решение:**
  - Лагранжиан моделируется как функциональный объект первого класса (Higher-Order Pure Function), отображающий `LocalState` в скалярную величину энергии $\mathbb{R}$.
  - Динамика выводится декларативно с помощью универсального оператора Эйлера–Лагранжа $E: (L) \to \text{StateDerivativeFunction}$.
  - Законы Ньютона $F = ma$ не кодируются вручную: они автоматически компилируются оператором $E$ из разности кинетической и потенциальной энергий:
$$L = T - V$$
- **Типовой контракт:**
```typescript
type Lagrangian<Q, V> = (state: LocalState<Q, V>) => number;

interface MechanicsEngine {
  eulerLagrangeOperator<Q, V>(L: Lagrangian<Q, V>): (state: LocalState<Q, V>) => StateDerivative<Q, V, any>;
  toAcceleration<Q, V>(L: Lagrangian<Q, V>): (state: LocalState<Q, V>) => any;
}
```

### 3. Паттерн «Композиция систем и декларативные связи» (System Aggregation & Constraints)
- **Контекст:** Сложная многокомпонентная система состоит из примитивных тел со своими степенями свободы и связей (шарниры, стержни, кинематические пары), наложенных между ними.
- **Архитектурное решение:**
  - **Компоненты (Primitives):** Каждое тело объявляет свой собственный свободный лагранжиан $L_{\text{free}} = T_{\text{free}} - V_{\text{free}}$.
  - **Связи (Constraint Adapters):** Связи моделируются как отображение координат независимого базиса $q_{\text{reduced}}$ в координаты составных частей $x_{\alpha} = f_{\alpha}(t, q_{\text{reduced}})$.
  - **Сборка (Aggregation):** Лагранжиан составной системы строится чистой функциональной композицией:
$$L_{\text{composite}} = \left(\sum_{\alpha} L_{\alpha}\right) \circ C(F)$$
где $C(F)$ — адаптер поднятия координатного преобразования до локального кортежа (процедура `F->C`).
- **Схема декомпозиции:**
$$\text{Free Components} \xrightarrow{L_1 + L_2 + \dots} L_{\text{free}} \xrightarrow{\circ C_{\text{constraint}}} L_{\text{composite}} \xrightarrow{\text{Euler-Lagrange}} \text{Equations of Motion}$$

### 4. Паттерн «Канонические адаптеры» (Canonical Transformation / State Adapters)
- **Контекст:** Решение задачи в исходных координатах может быть сингулярным (например, углы Эйлера при $\theta = 0$) или сильно связанным. Требуется преобразовать систему в альтернативный базис (действие–угол, кватернионы), сохранив неизменным инвариант физического закона.
- **Архитектурное решение:**
  - Каноническое преобразование моделируется как двусторонний адаптер фазового пространства $C_H: (t, q', p') \mapsto (t, q, p)$, удовлетворяющий симплектическому условию:
$$D C_H \cdot J \cdot (D C_H)^T = J$$
  - Если преобразование нестационарно (зависит от времени), адаптер обязан вычислять аддитивную добавку к новому гамильтониану:
$$H' = H \circ C_H + K, \quad \text{где } K = -p \cdot \partial_0 F(t, q')$$
  - Инвариант Лиувилля гарантирует, что адаптер не искажает информационную емкость системы и не приводит к потере состояний.
- **Пример замены сингулярного адаптера:**
  - Замена базиса углов Эйлера $(\theta, \phi, \psi)$ на несингулярный базис нормированных кватернионов $q = (q_0, q_1, q_2, q_3)$ устраняет геометрическую блокировку (Gimbal Lock) и деление на ноль в определителе матрицы $\partial_2 \partial_2 L$.

### 2. Классификация и изоляция связей (Constraints)

- [ ] В случае неголономных связей: изолирован ли алгоритм проецирования скоростей (принцип Д'Аламбера–Лагранжа) от стандартного вариационного солвера?
- [ ] Накладываются ли связи декларативно через композицию локальных кортежей (`F->C`), исключая ручной пересчет сил реакции в коде?

### 3. Чистота и разделение ответственности солвера и доменной модели
- [ ] Является ли функция лагранжиана/гамильтониана чистой (без побочных эффектов, статических полей, обращений к внешним сервисам)?
- [ ] Изолирован ли численный интегратор (Runge-Kutta, Bulirsch-Stoer, Verlet) от физического определения модели? (Интегратор должен принимать только `StateDerivativeFunction` и начальный кортеж).
- [ ] Для консервативных гамильтоновых систем: гарантируется ли использование именно **симплектического интегратора** (сохраняющего фазовый объем и 2-форму $\omega$)?

### 4. Аудит симметрий и инвариантов бизнес-логики (Теорема Нётер)

- [ ] Включены ли интегралы движения в тесты как инварианты верификации численной эволюции: $|\mathcal{I}(t) - \mathcal{I}(t_0)| < \epsilon_{\text{tol}}$?
- [ ] Используются ли циклические координаты для автоматического снижения размерности решаемой системы (Routhian Reduction)?

### 5. Анализ устойчивости и нелинейных резонансов
- [ ] Проведен ли линейный анализ устойчивости неподвижных точек через собственные значения матрицы Якоби?
- [ ] Классифицированы ли неподвижные точки (эллиптические — устойчивые, гиперболические — седловые/хаотические)?

- [ ] Выполнен ли расчет критерия перекрытия резонансов (Чирикова) для оценки порога перехода системы в режим крупномасштабного хаоса?
