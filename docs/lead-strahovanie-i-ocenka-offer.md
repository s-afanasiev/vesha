# Лид: «Страхование и оценка» (Курск) — что можем предложить

Локальный страховой агент (ИП Пономаренко М.А., продаёт полисы РЕСО-Гарантия и Ингосстрах) + смежная оценочная компания (ООО «Проф-оценка» / ИП Быкова). Услуги: ОСАГО/КАСКО/ОСГОП, аварийные комиссары, техосмотр, оценка ущерба (ДТП, залив, пожар), автоюрист. Три офиса, расширяются. Своего современного сайта нет: kursk2009.ucoz.ru мёртв (контент до 2017), prof-ocenka46.ru — шаблон 2010-х. Онлайн-жизнь идёт через OK-группу (12k+ подписчиков), VK, Яндекс.Карты, 2ГИС (4.9).

## Предложения (по возрастанию порога входа)

1. **Сайт** — современный сайт + SEO, объединяющий обе ветки (страхование и оценка), с калькулятором-лидформой (квалификация лида, не полный расчёт), записью на техосмотр и вызовом комиссара.
2. **CRM + автопролонгация** — база клиентов копится с 2009 года; автоматические напоминания клиентам о продлении ОСАГО (WhatsApp/Telegram) за месяц до окончания + воронка для агента. Главный денежный поток агента — продления.
3. **Генерация документов оценщика** — отчёты по ФСО и акты осмотра из шаблонов, фотоматериалы, расчёты ущерба; LLM-черновики описаний. Экономия часов работы оценщика.
4. **LLM-ассистент в соцсетях** — бот в OK/VK отвечает на типовые вопросы (КБМ, документы для ОСАГО, действия при ДТП) и передаёт квалифицированный лид агенту. Группа на 12k подписчиков — готовый канал.
5. **«Радар болей»** — коллекторы по локальным сообществам Курска (Подслушано, авто-группы), отзывам на Яндекс.Картах/2ГИС у них и конкурентов (Осаго46, Инко-Мед) → контент-план для их соцсетей, мониторинг конкурентов и изменений правил. Заодно — первый внешний кейс idea-radar.

## Стратегия захода

Начать с 1–2 (дёшево, осязаемо, быстрый эффект), 3–5 продавать затем как подписку. GPU VDS им не нужен: LLM-сервисы хостим сами. Бизнес небольшой, но растущий и платёжеспособный.
