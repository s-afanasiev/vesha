# Шпаргалка: подбор цветовой гаммы UI

Свод выжимок из исследований и отраслевых материалов (источники в конце).
Шпаргалка построена по **разрезам** — осям, по которым выбирается гамма.
Собрать палитру под заказчика = пройти все разрезы по порядку.

---

## Разрез 1. Психология оттенка: что несёт каждый цвет

| Цвет | Положительный эффект | Отрицательный эффект | Где применять в UI |
|---|---|---|---|
| **Синий** | Доверие, надёжность, спокойствие, безопасность | Холодность, снижает аппетит, «безэмоциональность» | Финансы, страхование, медицина, соцсети, инструменты длительной работы. Самый популярный цвет логотипов (~33% топ-брендов) |
| **Красный** | Энергия, срочность, страсть, аппетит | Опасность, агрессия, тревога | CTA-кнопки, e-commerce, еда; в интерфейсах — только точечно: ошибки, алерты |
| **Зелёный** | Здоровье, природа, рост, свежесть, расслабление | Скука, застой, «дешевизна» | Health, экология, финансы (рост), статусы «успех» |
| **Жёлтый** | Оптимизм, теплота, молодость | Тревога, осторожность (цвет предупреждающих знаков), утомляет | Акценты для дружелюбных брендов, детского сегмента; мелкими дозами |
| **Оранжевый** | Дружелюбие, энергия, неформальность | Незрелость, дешевизна (29% считают его наименее любимым) | Некорпоративные бренды, CTA (мягче красного), молодёжные сервисы |
| **Фиолетовый** | Премиальность, мудрость, креатив, женственность | Вычурность, избыточность | Люкс, креатив, женские аудитории; выделяет среди конкурентов |
| **Чёрный** | Люкс, мощность, современность, строгость | Тяжесть, траур, холодность | Люкс, мода, high-tech; фон тёмных тем |
| **Белый** | Чистота, минимализм, простор | Стерильность, пустота | Фон почти любого интерфейса, медицина, минимализм |
| **Розовый** | Молодость, забота, креатив | Детскость, приторность | Женские аудитории, kids, wellness |
| **Серый** | Строгость, зрелость, нейтральность | Скучность, безликость | Корпоративный B2B, фоны рабочих инструментов |

Источники: HubSpot (перечень с примерами брендов и статистикой), 99designs (психология + схемы).

**Научная база и оговорки.** Подтверждено исследованиями: синий→спокойствие/подход, красный→внимание к деталям и срочность (Mehta & Zhu, Science 2009; Elliot, Color-in-Context Theory — эффект цвета зависит от контекста задачи). Яркость сильнее всего даёт «удовольствие», насыщенность — «возбуждение» (Valdez & Mehrabian, модель PAD). Цифры вроде «90% первого впечатления — от цвета» — маркетинговые клише без строгой базы. Культурные различия существенны (белый: чистота на Западе / траур в части Азии), но ассоциации «синий=вода/небо» почти универсальны.

## Разрез 2. Домен: скелет палитры под тип бизнеса

| Домен | Скелет (фон → текст → акценты) | Почему работает | Чего избегать |
|---|---|---|---|
| Финансы, страхование | Белый/светло-серый → тёмно-серый → **синий + бирюза** | Доверие и надёжность — ядро услуги (пример N26: #2b6777 #c8d8e4 #52ab98) | Красные/кислотные массы, хаос |
| Медицина, health | Белый → тёмный → **зелёный + синий**, мягкие мятные | Здоровье, чистота, спокойствие | Чёрный (ассоциация траура), агрессивные акценты |
| Spa / wellness / релакс | Беж/персиковый → тёмно-графитовый → **пастельные розово-коралловые + лиловый** | Успокоение и уверенность одновременно (пример медитативной схемы #fae5df #ed7966 #303179) | Высокая насыщенность, контраст неон-уровня |
| Игры, развлечения | **Тёмный → белый → неоновые акценты** (жёлтый + неон-голубой) | Драйв, «вечерний клуб», высокий контраст (#5bccf6 #fcde67 #030e12) | Блеклые пастели, скучный серый |
| E-commerce | Белый → тёмный → **оранжевый/красный CTA** | Срочность и действие; красный — аппетит | Слишком много акцентного цвета |
| Корпоративный B2B | Светло-серый → графит → **сдержанный синий**, серые шкалы | Строгость, зрелость, «мы всерьёз» | Яркие мультяшные палитры |
| Образование, kids | Белый → тёмный → **синий + жёлтый + шалфейный зелёный** | Радость, забота, genuine (#1b4d89 #f9e45b #6db784) | Мрачные тона |
| Экология, organic | Кремовый → тёмно-зелёный → **зелёный + приглушённый жёлтый** | Природа и свежесть (#f5eec2 #416a59 #73a24e) | Синтетический неон |
| Еда, рестораны | Тёплый фон → тёмный → **красный + жёлтый** | Аппетит и быстрота (классика фастфуда) | Синие массы (подавляют аппетит) |
| Люкс, мода | Чёрный/кремовый → белый → **золото/минимум акцента** | Сдержанный премиум | Пёстрота, дешёвые градиенты |

Общая закономерность: **доверительные отрасли — холодные приглушённые + белый; эмоциональные — тёплые и насыщенные; entertainment — тёмный фон и высокий контраст; премиум — минимум цвета**.

## Разрез 3. Контекст задачи и режим

| Задача / контекст | Рекомендация | Основание |
|---|---|---|
| Длительная работа с текстом (CRM, канбан) | Тёмный текст на светлом фоне — дефолт; тёмная тема — вечерняя опция. Преимущество светлой растёт при мелком шрифте | Piepenbrock 2013, Dobres 2017 (обзор NN/g) |
| Привлечение внимания (CTA) | Один насыщенный акцент, контрастный фону; остальное нейтрально | Elliot 2015: синий — доверие, красный — выигрыш в зрительном поиске |
| Ошибки и тревога | Красный только для ошибок, деструктивных кнопок, просрочек; большими областями не заливать | Elliot 2015; Elliot & Maier 2012: красный перед сложной задачей снижает результат |
| Творческие задачи (брейншторм) | Синий фон/акценты вокруг | Mehta & Zhu 2009 (с оговоркой — см. ниже) |
| Детальная сверка | Красные маркеры для несовпадений; мелкий текст — в light mode | Mehta & Zhu 2009; NN/g |
| Ожидание, фоновые процессы | Спокойные светлые и холодные нейтральные тона | Jonauskaite et al. 2020 (30 стран) |

**Светлая vs тёмная тема.** Light выигрывает на задачах остроты зрения и корректуре — пользователи разницы не ощущают, но показывают её. Днём/в офисе светлая лучше, ночью тёмная быстрее. При астигматизме светлый текст на тёмном «расплывается» (halation); при катаракте — наоборот, тёмная читается легче (Legge 1985). На OLED тёмная экономит батарею. Вывод: light по умолчанию + постоянный тумблер (вечерние сессии); в тёмной теме не использовать чистый насыщенный красный на чёрном и поднимать яркость акцентов.

**Научные оговорки.** Прямая репликация Mehta & Zhu (Pritschet et al. 2016, PeerJ) эффект красного/синего не подтвердила, концептуальная (Xia et al. 2016) дала смешанные результаты; цвет на мониторе смешивается с яркостью, эффекты малы. Elliot 2015 включал только эффекты, реплицированные в ≥5 независимых лабораториях, но сам предупреждает про маломощные выборки и слабый контроль яркости. Культурные ассоциации универсальны лишь частично (красный = интенсивные эмоции обеих валентностей, тёмное = негатив — Jonauskaite 2020); значение зависит от контекста (синяя лента — первое место, синее мясо — гниль). Цвет — усилитель иерархии и семантики, а не замена компоновке; доверие пользователя строится на постоянстве, а не на оттенке.

## Разрез 4. Инженерия сборки (чтобы не получилось «красиво, но нечитаемо»)

1. **Роли**: любая палитра обязана покрыть — фон приложения, поверхности (карточки, сайдбар), состояния интерактива (normal/hover/active), текст основной и вторичный, акцент + цвет текста на нём, границы subtle/strong, семантика success/warning/danger.
2. **Эталон разбиения — Radix (12 ступеней)**: 1 — app bg, 2 — subtle bg, 3/4/5 — normal/hover/active, 6–8 — границы и focus, 9/10 — solid-заливка + hover, 11/12 — low/high-contrast текст. Solid-ступень 9 — максимум хромы; шкалы «Sky, Mint, Lime…» спроектированы под тёмный текст на solid.
3. **Правило 60–30–10**: 60% фон/нейтрали, 30% поверхности, 10% акцент.
4. **Контраст (WCAG AA)**: текст ≥ 4.5:1, крупный текст (≥24px или ≥18.5px bold) ≥ 3:1, не-текстовые элементы (границы инпутов, иконки, focus ring) ≥ 3:1. Пороги не округлять (4.4:1 = fail); плейсхолдер и hover-текст тоже требуют 4.5:1; исключения — логотипы, декор, disabled. Типичные ошибки: серый на сером, focus только цветом, состояние закодировано только цветом (дальтонизм), dark-тема не проверена.
5. **Перцептивное пространство**: HSL врёт — «L 50%» у жёлтого и синего воспринимается по-разному, `darken()` непредсказуем, смена hue молча ломает контраст. Строить шкалы в **OKLCH**: контраст предсказуем по разнице L (~0.2 = заведомо мало), hue стабилен при изменении хромы, кодирует P3-гамут. Альтернативы: Material 3 (тональные палитры HCT 0–100, доступность задаётся тоном), Leonardo (генерация шкал от целевого контраста).
6. **Гармония**: шаблоны Мацуды/Иттена (комплементарная, аналоговая, триадная) — формализованы Cohen-Or (SIGGRAPH 2006).
7. **Тёмная тема**: не «инвертировать», а переставить алиасы ролей на другие ступени (Radix: 3 ↔ 10), снизить хрому ярких цветов, контраст каждой пары проверить заново.
8. **Токены**: закрепить палитру как CSS custom properties / Design Tokens — компоненты используют только токены, никаких сырых hex.

## Алгоритм: подобрать гамму под заказчика за 10 шагов

1. Определи **домен** → возьми скелет из таблицы разреза 2.
2. Определи **эмоцию бренда** (доверие/драйв/релакс) → сверь с разрезом 1.
3. Выбери **акцент** по домену; проверь, что он отличается от конкурентов ниши. Нейтраль возьми не чисто серой, а с лёгким оттенком акцента.
4. Зафиксируй **роли** (фон/поверхности/текст ×2/акцент/границы/состояния).
5. Построй шкалы в **OKLCH** одной формулой: фиксированные L/C, семантики отличаются только hue (neutral/error/warning/success). Пропорция 60–30–10.
6. Назначь роли по ступеням (схема Radix, разрез 4.2) и выбери on-color для solid-акцента по контрасту, не «на глаз».
7. Проверь **контраст** каждой текстовой пары: body ≥ 4.5:1, крупный ≥ 3:1, границы/focus ≥ 3:1 (Leonardo или чекер).
8. Собери **тёмную тему** ремапом алиасов ролей (не инверсией), снизь хрому ярких цветов.
9. Проверь обе темы на реальном контенте (текст, таблица, карточка, focus/disabled), состояния продублируй нецветом (иконка/подпись).
10. Закрепи как **токены** (CSS custom properties) — компоненты используют только токены.

## Применение к нашим проектам

- Чат-движок: тема «приборной панели» = разрез 3 (длительная работа) + синий акцент (доверие, страховой менеджер) + насыщенные плашки только как индикаторы этапов; светлая тема — дефолт, «вечерняя» — тумблер.
- Генератор тем «под отрасль» (идея): скелет ролей Radix + OKLCH + вход — домен заказчика; выход — готовая рольная палитра. Маленький продукт и наглядное демо для лида.
