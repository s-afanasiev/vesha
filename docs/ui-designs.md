# Дизайн-направления витрины: набор из трёх тем

Документ описывает два дополнительных дизайна витрины к базовому «варианту А»
из [universal-framework.md](universal-framework.md) (§7: светлая база + Bento +
«жидкое стекло» + мягкие градиенты). Итог — тройка тем разного темперамента:
заказчику показываем характер, а не «единственно верный» макет.

Общее для всех тем (канон каркаса, §2 и §7): vanilla JS/CSS **без фреймворков
и сборки**, один веб-шрифт (Google Fonts) с системным фолбэком, палитра —
только через [ui-color-cheatsheet.md](ui-color-cheatsheet.md) с правилами ролей
(один тёплый акцент только у CTA, серые ≥ 4.5:1, состояния кодируются не только
цветом), таймерные циклы — рекурсивный `setTimeout`, `prefers-reduced-motion`
обязательно. Кабинет при любой теме витрины остаётся «приборной панелью» (§4).

---

## 0. Матрица выбора

| | А «Стекло» (§7 каркаса) | Б «Пространство» | В «Милый брутализм» |
|---|---|---|---|
| Настроение | доверие, чистота, премиум | глубина, «пощупай товар» | дружба, «местный, свой» |
| Материя | стекло + мягкие градиенты | слои, перспектива, объект | рамки, жёсткие тени, стикеры |
| Доп. вес | ~0 | ~9 KB gzip (Zdog, лениво) | ~0 |
| Реализация | `ocenka-site-v2` (готов) | CSS-3D + Zdog | чистый CSS |
| Главный риск | «типовая AI-гладкость» | перегруз на слабых телефонах | «несерьёзно» для строгих отраслей |
| Домены | страховой, аптека | автосервис, аптека, «продукт» | сантехник, автосервис |

Демо-стратегия: А — база по умолчанию; Б и В показываем как «характер» под
личность заказчика. Структура витрины (§3 каркаса) у всех тем одна — меняется
материя поверх каркаса: токены + декор + движение.

## 1. Дизайн Б — «Пространство» (псевдо-3D)

### 1.1 Идея

Сайт как витрина-сцена: у hero есть осязаемый объект (капсула, шестерня,
вентиль, щит), карточки живут в слоях с перспективой, страница дышит глубиной.
Никаких тяжеловесов: всё считается на клиенте, сервер остаётся статикой.

### 1.2 Стек — три яруса

- **Ярус 1, база — CSS-3D** (0 KB JS): `perspective` на секциях, tilt-карточки
  (rotateX/rotateY ≤ 6° по позиции курсора), слои-параллакс фона по скроллу,
  герой из 2–3 `translateZ`-слоёв. Приём уже есть в каркасе: 3D-coverflow
  карусель без WebGL (§3.3 universal-framework).
- **Ярус 2 — Zdog для героя-объекта** (~29 KB min / ~9 KB gzip, без
  зависимостей): плоский псевдо-3D «иллюстративного» стиля, рисует в SVG или
  Canvas; цвета берём из CSS-токенов → перекраска под отрасль бесплатна.
  Грузим лениво, после LCP.
- **Ярус 3, рост-точка — OGL** (~10 KB gzip): шейдерные фоны, если когда-нибудь
  понадобится настоящий свет/материалы. Three.js (~130–150 KB gzip) — не наш
  уровень и не наш формат (без сборки).

**Про вычисления на клиенте.** CSS-3D и WebGL считают GPU посетителя, Zdog —
CPU (перерисовка вектора в SVG/Canvas). Сервер не меняется вовсе: nginx отдаёт
статику как раньше, бэкенд не участвует. Цена клиента = вес библиотеки +
GPU/батарея телефона — отсюда ярусность и жёсткие правила ниже.

### 1.3 Витрина

- **Hero**: слева текст (вместо градиентного текста — «глубинная» подложка и
  тень), справа сцена: объект на подиуме, медленное idle-вращение (rAF),
  по драгу — вручную (Dragger из Zdog); карточка доверия — стекло-слой поверх
  сцены (`translateZ`).
- **Услуги**: bento-сетка остаётся, карточки получают «этажи» — иконка на
  `translateZ(30px)`, тень «нависания», hover — подъём (transform-only).
- **Карусель**: как в каркасе, но `perspective: 1200px`, тени глубины, пол-отражение.
- **Модалка услуги**: фон уходит (`scale(.97)` + blur), модалка «приезжает» из глубины.
- **Виджет-чат и формы**: без 3D — конверсионные элементы не должны притворяться сценой.

### 1.4 Производительность и доступность (жёсткие правила)

- Анимируем только `transform`/`opacity`; `will-change` точечно, не «на всё».
- Zdog: ленивый `<script>` после события `load`; рендер останавливается, когда
  hero вне экрана (IntersectionObserver) и когда вкладка скрыта
  (visibilitychange); devicePixelRatio кап = 2; idle-вращение замирает во время
  взаимодействия пользователя.
- `prefers-reduced-motion: reduce` → статичный SVG вместо сцены (тот же
  рисунок, движок не грузится вообще).
- Фолбэк без JS: статичный SVG героя — он и есть базовый слой, Zdog лишь
  оживляет его.
- Бюджет: весь 3D-слой ≤ 40 KB (Zdog ~9 + свой код ≤ 15 + сцена/данные ≤ 5 +
  запас), цель 60 fps на среднем Android, демо не греет телефон за 10 минут.

### 1.5 Объекты под отрасли (Zdog-миниатюры)

аптека — капсула; автосервис — шестерня/поршень (в прототипе — колесо);
сантехник — вентиль; страховой/оценщик — щит; универсальный фолбэк —
куб-подиум с логотипом.

### 1.6 Чек-лист сборки Б

1. Палитра по шпаргалке → токены `:root`.
2. Витрина на разметке варианта А: «стеклянную» материю заменить на слои и
   перспективу (hero, услуги, модалка).
3. Статичный SVG героя → ленивый Zdog поверх (паузы по §1.4).
4. Tilt-карточки и параллакс — CSS, без JS где возможно.
5. Карусель/модалка с глубиной.
6. Проверки: reduced-motion, троттлинг CPU 4× в DevTools, мобильный 390px,
   10-минутный тест батареи/нагрева, фолбэк без JS.

## 2. Дизайн В — «Милый брутализм»

### 2.1 Идея

Плакат + стикеры: толстые тёмные рамки, жёсткие офсет-тени без blur,
продавливающиеся кнопки, наклеенные стикеры-эмодзи, плакатная типографика.
Это современное продолжение материальной темы chat-engine: фаски → рамки,
нажимающиеся кнопки → продавливание. Отличие от анти-сеточного брутализма:
сетка аккуратная, «хаос» живёт только в декоре.

### 2.2 Токены

- `--ink` — почти чёрный; фон — крем/молочный (класс `#FFF6E9`), не белоснежный.
- Рамки `2–3px solid var(--ink)`; тень `5–7px 7px 0 var(--ink)`, blur = 0.
- Радиусы: карточки 10–16px, пилюли 999px, разделители/«сырые» блоки 0.
- Акценты: 2–3 сочных по домену из шпаргалки (жёлтый/розовый/бирюза);
  CTA — единственный тёплый (правило `f8c37af` сохраняется).
- Шрифт: один жирный гротеск с кириллицей — Rubik 400/700/900 (или аналог из
  Google Fonts); заголовки — 900, caps, плотный трекинг.

### 2.3 Приёмы

- **Кнопки**: hover — тень съезжает; active — `translate(6px,6px)` и тень
  схлопывается в ноль (продавливание, родня кнопкам chat-engine).
- **Стикеры**: absolute-бейджи с наклоном −3…3°, эмодзи + подпись, «скотч» —
  полупрозрачная полоска сверху; всегда `aria-hidden`, только декор.
- **Marquee-полоса доверия**: бегущая строка «✔ Без предоплаты ✔ Официально
  ✔ Сегодня…» (CSS-анимация, при reduced-motion — статичная строка).
- **Hero**: H1-плакат (допустима обводка текста), цифры доверия оформлены как «ценники».
- **Форма заявки**: большие поля с рамками; focus — двойная обводка + тень (не только цвет!).
- **Услуги**: карточки-ценники; статьи — «записки на полях».

### 2.4 Кабинет

Остаётся приборной панелью (§4 universal-framework). Одна деталь на стыке:
канбан-карточки — стикеры с лёгким наклоном по этапу (±1–2°) и рамкой цвета
этапа. Авторизацию, диалоги и таблицы не «мило-бруталим» — рабочая среда
должна отличаться от витрины.

### 2.5 Доступность и риски

- Чернила на креме > 12:1; состояния ≠ только цвет; стикеры не несут смысл.
- Осторожно в строгих отраслях (страхование, аптека): приглушённая версия —
  пастельнее акценты, минимум стикеров, без marquee.
- Полная сила — сантехник, автосервис, локальные услуги.

### 2.6 Чек-лист сборки В

1. Палитра по шпаргалке: крем + чернила + доменные акценты.
2. Один блок токенов: рамки/тени/радиусы/продавливание.
3. Витрина из разметки варианта А: заменить материю карточек и кнопок.
4. Стикеры и marquee — декор поверх структуры, `aria-hidden`.
5. Канбан-стикеры в кабинете (опционально).
6. Проверки: контраст, reduced-motion (marquee и наклоны выключены), мобильный 390px.

## 3. Отброшенные направления и почему (чтобы не возвращаться)

- **Glassmorphism 2.0** — уже внутри варианта А («жидкое стекло»).
- **Creative Process** — нужны подлинные артефакты (сканы, наброски); у аптеки
  и сантехника «кухни» нет.
- **Y2K** — блеск и конфетные градиенты конфликтуют с доверием (шпаргалка,
  разрез 2); разве что точечный акцент.
- **Анти-сеточный брутализм** — сломанная сетка и моноширинка бьют по конверсии
  и мобильной читаемости; «инженерность» уже закрыта приборным кабинетом.
- **Гиперминимализм** — сильный запасной вариант (аптека/страхование, самый
  дешёвый), но слабее отстройка от А; вернуть, если В покажется слишком дерзким.
