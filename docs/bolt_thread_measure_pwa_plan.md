# Технический план разработки PWA-утилиты: Измерение резьбы и параметров крепежа по фото (WASM + Microtransactions)

---

## 1. Архитектура и концепция решения

Проект представляет собой сверхлегкое клиентское PWA-приложение, предназначенное для мгновенного определения шага и диаметра резьбы болтов/винтов без использования тяжелых нейросетевых моделей.

### Ключевые принципы:
* **Zero Backend Costs:** Все расчеты и обработка изображений происходят на устройстве пользователя через WebAssembly (WASM).
* **Метрологическая точность:** Использование классических детерминированных алгоритмов Computer Vision (1D Spatial Projection + Автокорреляция / БПФ) вместо вероятностных нейросетей.
* **Минимальный размер бандла:** Общий вес приложения < 1 МБ.
* **Автономность:** Полная работоспособность офлайн через Service Worker.
* **Бизнес-модель:** Микротранзакции (пакеты сканирований, например 20 замеров за 10¢ / 10 ₽).

## 2. Математический алгоритм измерения шага резьбы

```
[ Кадр с камеры ] ──► [ ROI Трафарета ] ──► [ Фильтр Собеля ] ──► [ 1D-Проекция ] ──► [ Автокорреляция ] ──► [ Snapping к ГОСТ ]
```

### Этап 1. Захват и калибровка масштаба (ROI)
* Пользователь совмещает болт с экранным трафаретом (видоискателем) и помещает в выделенную зону калибратор (монету $D_{ref}$ мм).
* Масштаб кадра:
  $$	ext{Scale} = rac{D_{ref\_	ext{mm}}}{D_{ref\_	ext{px}}} \quad (	ext{мм/пиксель})$$

### Этап 2. Предобработка полоски резьбы
1. Перевод прямоугольной зоны резьбы (ROI) в Grayscale.
2. Применение вертикального оператора Собеля ($K_y$) для выделения границ витков:
   $$G_y = I * K_y$$

### Этап 3. Сжатие в одномерный профиль (1D Spatial Collapse)
Суммирование градиентных значений по горизонтали для каждой вертикальной координаты $y$:
$$S(y) = \sum_{x=0}^{W-1} |G_y(x, y)|$$
Полученный одномерный сигнал $S(y)$ представляет собой квазигармоническую кривую, где локальные максимумы соответствуют гребням витков.

### Этап 4. Поиск периода через автокорреляцию (ACF)
Для устранения шума, ржавчины и локальных смазов применяется дискретная автокорреляция:
$$R(	au) = \sum_{y} S(y) \cdot S(y + 	au)$$
* **Основной шаг в пикселях ($\Delta p$):** координата первого выраженного максимума $R(	au)$ при $	au > 	au_{min}$.
* **Расчетный шаг в миллиметрах:**
  $$P_{calc} = \Delta p \cdot 	ext{Scale}$$

### Этап 5. Автоподгонка к стандартам (ISO / DIN / ГОСТ)
Значение $P_{calc}$ сопоставляется с таблицей стандартных шагов:
$$\mathbf{P_{std}} = [0.5, 0.7, 0.75, 0.8, 1.0, 1.25, 1.5, 1.75, 2.0, \dots]$$
$$P_{final} = rg\min_{p \in \mathbf{P_{std}}} |p - P_{calc}|$$

## 3. Архитектура PWA и UX/UI

### Технологический стек:
* **Frontend:** Vite + Vanilla JS / Preact / Tailwind CSS (минимальный оверхед).
* **WASM Core:** Скомпилированный C++/Rust микро-модуль для быстрого расчета ACF/FFT (< 100 КБ) или урезанная сборка OpenCV.js.
* **Камера:** `navigator.mediaDevices.getUserMedia` с захватом полного разрешения через `ImageCapture.takePhoto()`.
* **Хранилище:** `IndexedDB` / `localStorage` (кэш бесплатных и купленных сканов, история замеров).

### Пользовательские экраны:
1. **Видоискатель:**
   * Полупрозрачный SVG-оверлей с разметкой под болт и калибровочную монету.
   * Акселерометр/гироскоп (`DeviceOrientation API`) для проверки горизонтальности съемки.
2. **Экран результата (< 100 мс):**
   * Крупные карточки: **Тип резьбы (М10)**, **Шаг (1.5 мм — крупная)**, **Диаметр стержня (9.85 мм)**.
   * Визуальный контроль: наложение витков виртуальной резьбы поверх реального фото для проверки оператором.
3. **Модальное окно баланса:**
   * Счетчик оставшихся замеров.
   * Кнопка покупки пакета (1 клик).

## 4. Упаковка и публикация в магазины приложений

```
                         ┌──► Google Play (TWA / Bubblewrap)
                         │
[ Исходный PWA Репозиторий ] ──► RuStore / APK (Bubblewrap / Capacitor)
                         │
                         └──► Apple App Store (Capacitor Shell + WKWebView)
```

### 1. Google Play (Android): Trusted Web Activities (TWA)
* Не требует написания нативного кода на Java/Kotlin.
* **Инструмент:** `@bubblewrap/cli`.
* **Команды сборки:**
  ```bash
  npm install -g @bubblewrap/cli
  bubblewrap init --manifest=https://app-domain.com/manifest.json
  bubblewrap build
  ```
* **Привязка домена:** Размещение `assetlinks.json` в `/.well-known/assetlinks.json` на сервере PWA для бесшовного запуска без адресной строки Chrome.

### 2. Apple App Store (iOS): Capacitor Shell
* Оборачивание в легковесный контейнер `WKWebView`.
* **Инструмент:** `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`.
* **Команды:**
  ```bash
  npm install @capacitor/core @capacitor/cli
  npx cap init BoltMeasure com.app.boltmeasure
  npx cap add ios
  npx cap copy ios
  ```

### 3. RuStore & Прямой APK:
* Использование APK-файла, сгенерированного Bubblewrap или Capacitor.

## 5. Реализация микроплатежей в магазинах и Web

| Платформа | Инструмент монетизации | Механизм |
| :--- | :--- | :--- |
| **Google Play (TWA)** | Digital Goods API / Play Billing | Списание за расходуемые товары (Consumable In-App Products). |
| **App Store (iOS)** | StoreKit через `@capacitor/in-app-purchases` | Покупка пакетов сканирований через Apple ID. |
| **Web / RuStore** | СБП / ЮKassa / Stripe API | Прямой эквайринг и генерация токена пакета в IndexedDB. |
