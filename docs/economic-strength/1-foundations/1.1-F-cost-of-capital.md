# 1.1-F. Цена капитала для промышленного и софтверного проекта — что отсекает ставка

Документ измеряет цену денег для промышленного проекта в России и панели (Китай, Германия, США, Корея, Турция, Бразилия), раскладывает её на компоненты (безрисковая ставка, страновой спред, инфляция, институциональный остаток), фиксирует двухуровневый кредитный рынок (льготные программы против рыночной ставки) и показывает, какие классы проектов (станки, микроэлектроника, тяжёлое ПО, SaaS, робототехника) проходят инвестиционный фильтр при ставках 10/18/25 %, а какие отсекаются. Ряды — реальные (ЦБ, FRED, Damodaran, WDI, ФРП), за исключением помеченных статусов: структура инвестиций по источникам (Росстат — сайт недоступен из среды) и портфель ФРП — ручной сбор v1.

## 0. Резюме

- **Вопрос.** Какова стоимость капитала (WACC) для промышленного проекта в России против панели и из чего она складывается; как ключевая ставка и льготные программы меняют цену денег для разных заёмщиков; какая доля инвестиций — частные внебюджетные источники; какие классы проектов окупаются, а какие отсекаются.
- **Ответ.** Цена денег для российского проекта двухслойна. Валютная рамка (метод Дамодарана, 2024): стоимость собственного капитала России 12,34 % (безрисковая США 4,21 % + ERP 8,13 %) против 8,67 % у США и 6,24–9,35 % у Германии/Кореи/Китая; Россия дороже США на 3,67 п. п. Рублёвая рамка (факты 2024): ключевая ставка 17,54 % (средняя за год), кредит нефинансовым организациям 17,09 %, депозит 14,62 %; разложение: 17,54 % = 6,77 % (валютный эквивалент: 4,21 % госдолг США + 2,56 % суверенный спред) + 8,43 % (инфляция) + 2,34 п. п. (остаток — ожидания, риск, жёсткость ДКП). Модельный рублёвый WACC проекта — 20,87 % (при допущениях wE=0,6; β=1). Двухуровневый рынок: ФРП выдаёт займы под 3–5 % (5 млн – 2 млрд руб., до 7 лет) — разрыв с рыночной ставкой 12–14 п. п.; охват льготного контура численно не собран (статус). Отсечение проектов: при ставке 25 % окупаются только проекты с устойчивой отдачей ≥30 % инвестиции в год (8 лет); завод станков (IRR 22,3 %) не проходит фильтр 25 %, фабрика ЭКБ (11,5 %) отсекается при любом WACC выше 12 %, быстрый SaaS (37,5 %) и робоячейка (39,6 %) проходят. Доля частных внебюджетных источников в инвестициях — статус (сайт Росстата недоступен из среды; ручной сбор v1).
- **Три числа.** (1) 10,78 п. п. — разрыв рублёвой и валютной безрисковой ставки в 2024 г. (ключевая 17,54 − 6,77). (2) 14,1 п. п. — разрыв между ставкой ФРП (3 %) и рыночным кредитом (17,09 %) — «геометрия» двухуровневого рынка. (3) 22,3 % — IRR модельного завода станков против 25 % порога: станкостроение живёт только ниже порога.
- **Что делать.** Критерий S2 «объём льготного портфеля и его доля в инвестициях промышленности» численно не выполнен — нужен ручной сбор отчётности ФРП/ВЭБ (v1). До этого доля льготного контура в цене денег не квантифицируется.
- **Уверенность.** Ряды ставок и премий — реальные, свежие (ЦБ до 16.10.2026, FRED/Damodaran 2026); средняя-высокая для фактов, средняя для модели (профили проектов — модельные допущения, помечены [О]).

## 1. Вопрос и гипотезы

**Вопросы плана (дословно):**

1. Какова стоимость капитала (WACC) для промышленного проекта в России по сравнению с панелью и из чего она складывается (безрисковая ставка, страновая премия, институциональная премия)?
2. Как ключевая ставка и льготные программы (займы ФРП, субсидирование ставок, проектное финансирование) меняют реальную цену денег для разных классов заёмщиков?
3. Какая доля инвестиций в основной капитал приходится на частные внебюджетные источники и как она реагирует на институциональные шоки?
4. Какие классы проектов окупаются при текущей стоимости капитала, а какие отсекаются (станкостроение, микроэлектроника, тяжёлое ПО)?

**Соответствие разделов:** вопрос 1 — 3.1; вопрос 2 — 3.2; вопрос 3 — 3.3; вопрос 4 — 3.4.

**Гипотеза H1** (медленные переменные задают потолок): цена капитала — фильтр, через который институциональные дефекты (слабая защита прав, волатильность правил) транслируются в отбор проектов. Если так, длинные технологические проекты отсекаются не «нехваткой денег», а их ценой: модель 3.4 показывает это на классах проектов `[Г: H1]`.

## 2. Данные и методы

**Ряды (загружены, реальные).**
1. **Ключевая ставка РФ** — ЦБ, дневной ряд 2013-09-17 … 2026-10-16 (3281 наблюдение), годовые средние; 2024: 17,54 %, 2025: 19,13 %, 2026 (по 16.10): 14,72 % `[Ф]`.
2. **Кривая ОФЗ** — ЦБ, последняя доступная дата (16.10.2026): ОФЗ 10 лет — 16,51 %. Исторический ряд по годам сайтом не отдаётся (проверено: параметр даты игнорируется) — ограничение `[Ф, О]`.
3. **10-летние госдоходности панели** — FRED: США (2024: 4,21 % средняя за год), Германия, Корея; Россия — только до 2018 г.; Турция/Бразилия/Китай — серии недоступны (404) → валютная рамка через Damodaran `[Ф]`.
4. **Страновые премии Damodaran** (февраль 2026): суверенный спред, CRP, полная ERP, налог. Россия: спред 2,56 %, CRP 3,90 %, ERP 8,13 % `[Ф]`.
5. **Ставки и инфляция WDI** (2010–2024, 7 стран): кредитная, депозитная, реальная кредитная, инфляция `[Ф]`.
6. **ФРП** — условия основных программ (выгрузка 2026-10-18): 3 % и 5 % годовых, 5 млн – 2 млрд руб., до 7 лет `[Ф]`.

**Модель (все допущения — [О], правятся в одном блоке скрипта `wacc-cutoff.mjs`).** Стандартный промышленный проект: wE = 0,6, wD = 0,4, β = 1, налог 20 % (ставка НК РФ 2024; с 2025 — 25 %). Валютная рамка: Ke = Rf(US10Y) + ERP(страны); Kd = Rf + суверенный спред; WACC$ = 0,6·Ke + 0,4·Kd·(1−t). Рублёвая рамка: Ke = ключевая + ERP; WACC = 0,6·Ke + 0,4·ставка кредита·(1−t). Отсечение: максимальный срок окупаемости N при ставке r и маржинальности m: N = −ln(1−r/m)/ln(1+r) (при m ≤ r окупаемость не наступает); IRR типовых профилей — численно (бисекция).

**Открытые статусы (ручной сбор, v1).** Структура инвестиций по источникам (Росстат — сайт недоступен из среды; ЕМИСС не разобран); портфель ФРП (число и объём займов); КИП/СПИК/СЗПК (охват). Числа не подставляются до сбора.

**Разметка.** `[Ф]` — данные источников, `[О]` — расчёты/модель, `[Э]` — суждения, `[Г]` — гипотезы. Паспорта — `data/1.1-F/passports.md`; CSV — `keyrate-annual.csv`, `ofz-curve-latest.csv`, `wacc-panel.csv`, `russia-cost-of-capital.csv`, `russia-ruble-decomposition.csv`, `payback-cutoff.csv`, `project-classes-cutoff.csv`.

## 3. Результаты

### 3.1. WACC: Россия против панели и разложение цены (Вопрос 1)

**Валютная рамка (метод Дамодарана, год 2024, β = 1, wE/wD = 60/40; для всех стран общая база — госдолг США)** `[О; Ф]`:

| Страна | Рейтинг | Спред, п. п. | CRP, п. п. | ERP, % | Ke, % | WACC$, % | Локальная ставка кредита, % |
|---|---|---|---|---|---|---|---|
| Россия | NR | 2,56 | 3,90 | 8,13 | 12,34 | 9,57 | 17,09 |
| Турция | Ba3 | 3,06 | 4,66 | 8,89 | 13,10 | 10,04 | — |
| Бразилия | Ba1 | 2,13 | 3,24 | 7,47 | 11,68 | 8,68 | 40,23 |
| Китай | A1 | 0,60 | 0,91 | 5,14 | 9,35 | 7,05 | 4,35 |
| Корея | Aa2 | 0,42 | 0,64 | 4,87 | 9,08 | 6,81 | 4,73 |
| США | Aa1 | 0,23 | 0,23 | 4,46 | 8,67 | 6,53 | — |
| Германия | Aaa | 0,00 | 0,00 | 4,23 | 8,44 | 6,24 | — |

Чтение: **Россия дороже США на 3,67 п. п. по стоимости собственного капитала** и на 3,04 п. п. по WACC — но не самый дорогой рынок панели: Турция дороже (Ke 13,10 %). Разница между Россией и США на 9/10 — страновой блок (спред + CRP = 6,46 п. п.), не «безрисковая» часть.

**Рублёвая рамка (факты 2024, ЦБ/WDI)** `[Ф; О]` — ключевая ставка 17,54 % (средняя за год; 2025: 19,13 % — максимум ряда; на 16.10.2026: 14,00 %), кредит нефинансовым организациям 17,09 %, депозит 14,62 %, реальная ставка по кредитам 5,82 %, инфляция 8,43 %.

**Разложение (сверху вниз)** `[О]`: 17,54 = **6,77** (валютный эквивалент безрисковой: 4,21 % US10Y + 2,56 % суверенный спред) + **10,78** п. п. разрыва рублёвой и валютной безрисковой; внутри разрыва: **8,43 п. п. — инфляция** и **2,34 п. п. — остаток** (инфляционные ожидания, премия за риск, жёсткость ДКП). Иными словами: рублёвая цена денег почти целиком «инфляционная надстройка» плюс небольшая рисковая премия; институциональная компонента разрыва мала на фоне инфляционной — **но именно она определяет разрыв с США в валютной рамке (спред + CRP)**.

**Динамика ключевой ставки (годовые средние, %)** `[Ф]`: 2013: 5,50 → 2014: 7,97 → 2015: 12,48 (шок) → 2016–2019: 10,56→7,31 (стабилизация) → 2020: 5,03 (пандемия) → 2021: 5,77 → 2022: 10,55 → 2023: 10,01 → **2024: 17,54 → 2025: 19,13** (максимум истории режима) → 2026 (по 16.10): 14,72. Цена денег для проекта не только высока, но и **волатильна**: коридор годовых средних — от 5,0 % до 19,1 % за 13 лет.

**ОФЗ:** доходность 10-летних — 16,51 % на 16.10.2026 `[Ф]` (единственная доступная точка; исторический ряд — статус).

### 3.2. Двухуровневый рынок кредита: льготный контур против рыночной ставки (Вопрос 2)

**Геометрия рынка (2024)** `[Ф]`: рыночный кредит нефинансовым организациям — 17,09 %; займы ФРП по основным программам — **3 % и 5 %** (5 млн – 2 млрд руб., до 7 лет; −2 п. п. при гарантиях ВЭБ/Корпорации МСП) — разрыв с рыночной ставкой **12–14 п. п.**; ключевая ставка 17,54 % задаёт пол. Модельный рублёвый WACC по рыночным условиям — **20,87 %** `[О]`; по льготной ставке 5 % — 17,0 % (0,6·25,67 + 0,4·5·0,8): скидка к WACC ~3,9 п. п. — но это **ловушка агрегата**: ключевой эффект ФРП не в скидке к WACC, а в **доступе** (проект без залоговой базы не получает рыночного кредита вовсе — это отбор, а не скидка) и **сроке** (7 лет против рыночных коротких графиков) `[Э]`.

**Классы заёмщиков (карта, `[Э]`):**
1. **Льготный контур** (ФРП, КИП, СПИК/СЗПК — стабилизационные оговорки из 1.1-D): крупные и средние проекты, прошедшие ведомственный отбор; ставка 3–5 % + защита условий. Цена входа — транзакционные издержки отбора и соответствие приоритетам.
2. **Рыночный контур**: кредит по ставке 17 %+ при реальной ставке 5,8 % (2024) — кредитуются компании с залогом и коротким оборотом; долгосрочные промышленные проекты при такой ставке не проходят фильтр 4 (3.4).
3. **«Из своих»**: крупные сырьевые и бюджетные корпорации финансируют инвестиции из прибыли (структура — статус, 3.3); для них цена капитала — альтернативная доходность депозита 14,62 % `[Ф]`: проект должен приносить больше депозита.

**КИП/СПИК/СЗПК:** механизмы существуют, условия (субсидируемая ставка, стабилизационные оговорки) подтверждаются планом и 1.1-D; **охват — не собран** (ручной сбор, v1). Критерий S2 «объём льготного портфеля и его доля в инвестициях промышленности» — **не выполнен численно**: отчётность ФРП/ВЭБ — ручной сбор (v1); фиксируется как статус.

### 3.3. Структура инвестиций по источникам (Вопрос 3)

**Статус.** Ряды Росстата «инвестиции в основной капитал по источникам финансирования» (собственные средства, кредиты банков, бюджетные средства) за 2010–2025 гг. **не собраны**: сайт Росстата недоступен из среды агента (сеть), ЕМИСС не разобран; машиночитаемого доступа нет (`искали, не нашли`); ручной сбор — v1. Числа не подставляются.

**Что известно из смежных документов** `[Э]`: инвестквота 2023–2024 гг. росла при высокой неопределённости и высокой ставке (27,3 % и 26,5 % ВВП, см. 1.1-D), что указывает на бюджетную природу части подъёма; разделение частных/государственных вложений — ровно та переменная, которой не хватает и здесь. Вопрос 3 остаётся открытым; его решение — ручной сбор 1–2 форм Росстата (v1).

### 3.4. Таблица отсечения классов проектов (Вопрос 4)

**Срок окупаемости (лет до NPV = 0) при ставке r и устойчивой маржинальности m — отдаче в % от инвестиции в год** `[О]`:

| Ставка | m = 15 % | m = 20 % | m = 30 % | m = 40 % | m = 50 % |
|---|---|---|---|---|---|
| r = 10 % | 11,5 | 7,3 | 4,3 | 3,0 | 2,3 |
| r = 18 % | не окупается | 13,9 | 5,5 | 3,6 | 2,7 |
| r = 25 % | не окупается | не окупается | 8,0 | 4,4 | 3,1 |

Читается так: при ставке 25 % проект с отдачей 20 % не окупается **никогда** (текущая стоимость потока < вложений); при отдаче 30 % — окупается за 8 лет; при 18 % и отдаче 20 % — за 14 лет (горизонт, недоступный для частного инвестора при волатильной ставке). **Порог выживания при высокой ставке — отдача ≥ 30 % в год на устойчивой фазе.**

**IRR типовых профилей (модельные, `[О]`; 12 лет, профили — допущения из скрипта)** и прохождение фильтра при WACC 10/18/25 %:

| Класс проекта | Год первого потока | Устойчивая отдача | IRR | 10 % | 18 % | 25 % |
|---|---|---|---|---|---|---|
| Быстрый SaaS / инженерный инструмент | 1 | 55 % | 37,5 % | да | да | да |
| Роботизированная ячейка (интеграция) | 1 | 50 % | 39,6 % | да | да | да |
| Завод станков | 2 | 40 % | 22,3 % | да | да | **нет** |
| Фабрика ЭКБ (микроэлектроника) | 3 | 28 % | 11,5 % | да | **нет** | **нет** |
| Тяжёлый САПР / PLM | 2 | 50 % | 26,7 % | да | да | да |

**Сопоставление с фактической ставкой** `[О; Ф]`: рублёвый WACC-модель 2024 г. — 20,87 %; рыночная ставка кредита 17,09 %; ключевая 17,54 % (2025: 19,13 %). В этом режиме: **завод станков (22,3 %) — на границе** (проходит 18 %, режется 25 %); **фабрика ЭКБ (11,5 %) отсекается безусловно** при любой рыночной ставке (нужна льготная/бюджетная ставка ≤10 %); софт и робототехника проходят даже дорогой фильтр (короткий цикл, высокая отдача). Станкостроение и микроэлектроника окупаются **только в льготном контуре** (3.2) или на бюджете — не потому что «нет денег», а потому что при 17–21 % их денежные потоки не догоняют ставку `[Э]`. Это ответ на вопрос 4: дорогая ставка работает как **селектор против длинных аппаратных цепочек и в пользу коротких цифровых**.

## 4. Кейсы

1. **ФРП (7 лет, 3–5 %):** срок займа сравним с горизонтом окупаемости станкостроительного проекта (5,5–8,0 лет при отдаче 30 % и ставке 18–25 %) — параметры программы откалиброваны под отсечение 3.4; при рыночной ставке тот же проект не финансируется `[Э]`.
2. **2015 и 2022–2025 (ставка-волна):** ключевая средняя 12,48 % (2015) и 17,54–19,13 % (2024–2025) — два эпизода, когда фильтр 3.4 закрывался для всего, кроме коротких проектов; связка с 1.1-D: скачки неопределённости и ставки синхронны, но независимо проверить вклад каждого фактора на агрегатах нельзя (1.1-D, 3.2) `[Ф; Э]`.
3. **ОФЗ 16,51 % (16.10.2026):** безрисковая альтернатива для «своих денег»: инвестировать в проект имеет смысл только выше этой планки (плюс премия) — фон для решений о капитале крупных корпораций `[Ф; Э]`.

## 5. Альтернативные объяснения

1. **Профили проектов — модельные.** IRR станков (22,3 %) и ЭКБ (11,5 %) зависят от допущений об отдаче (40 %/28 %); при более высокой отдаче (конструкторское ПО в станкостроении, сервисные контракты) фильтр проходится. Вывод «отсекается ставкой» верен при данных допущениях; чувствительность проверяется правкой одного блока параметров `[О]`.
2. **Не только ставка.** Низкая отдача станкостроения может отражать масштаб рынка, курс, конкуренцию с импортом — цена капитала лишь **усиливает** отсечение, не создаёт его `[Э]`.
3. **Льготный капитал без дисциплины отбора** может вести к отрицательной селекции (проекты живут на субсидии, а не на рынке) — риск программы, не измерен (нужны данные результативности ФРП, v1) `[Э]`.
4. **β = 1 и структура 60/40** — стандартные допущения; при β = 1,2 Ke России ≈ 13,1 %, WACC$ ≈ 10,0 %; ранжирование стран не меняется `[О]`.
5. **Валютная и рублёвая рамки не сводятся одна к другой** без модели инфляции/девальвации; в документе они показаны рядом, а не слиты `[О]`.

## 6. Выводы

1. Цена капитала для российского проекта двухслойна: валютная (Ke 12,34 %, WACC$ 9,57 % — дороже США на 3,7 и 3,0 п. п. соответственно) и рублёвая (кредит 17,09 %, модельный WACC 20,87 %, ключевая 17,54 % в 2024; 19,13 % в 2025) `[Ф; О]`.
2. Разложение рублёвой ставки: 6,77 % валютный эквивалент + 8,43 % инфляция + 2,34 п. п. остаток; разрыв с США на 90 % страновой (спред + CRP 6,46 п. п.) `[О]`.
3. Двухуровневый рынок: ФРП 3–5 % против 17,09 % — разрыв 12–14 п. п.; реальный эффект льготного контура — доступ и срок, не только ставка; охват — статус (v1) `[Ф; Э]`.
4. Отсечение: при ставке ≥18–21 % завод станков на границе, фабрика ЭКБ отсекается всегда, SaaS/робототехника/САПР проходят; ставка — селектор против длинных аппаратных цепочек `[О]`.
5. Структура источников инвестиций (вопрос 3) — открытый статус: без Росстата доля частных внебюджетных источников не измеряется; ручной сбор v1 `[статус]`.
6. Для `1.1-Σ`: цена капитала — передаточный механизм институционального профиля: дефекты (1.1-A…E) дают спред + CRP + волатильность ставки, которые в фильтре 3.4 режут именно длинные технологические проекты `[Э; Г: H1]`.
