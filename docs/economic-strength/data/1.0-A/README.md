# 1.0-A. Пилотный расчёт индекса силы экономики — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.0-A/calc-index.mjs
```

**Что делает скрипт:**

1. Скачивает 8 рядов WDI (Всемирный банк) по 32 странам панели, 1990–2024 гг.; сырые ответы API сохраняет в `data/economic-strength/1.0-A/raw/` с датой загрузки в имени файла.
2. Выбирает опорный год по каждому ряду (последний год 2021–2024 с покрытием ≥ 26 стран).
3. Считает эпизоды шоков (2008–2009, 2014–2015, 2020, 2022): глубину спада и время восстановления до докризисного пика (методика, раздел 3.4 документа).
4. Нормализует индикаторы (винзоризация 5/95, min–max, учёт направления), собирает 4 субиндекса и три композитных балла (равные / экспертные / PCA-веса), проводит Монте-Карло (1000 итераций, шум значений ±10 %, весов ±25 %, зерно фиксировано).
5. Делает ретро-проверку: корреляция Спирмена между значением индикатора в 2005 г. и среднегодовым ростом ВВП на душу 2005–2024 гг.
6. Пишет три CSV (разделитель `;`, кодировка UTF-8 с BOM) и печатает краткий отчёт в консоль.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `pilot-30-countries.csv` | 31 страна: ранги, 4 субиндекса, сводный балл при 3 схемах весов, интервал и размах ранга Монте-Карло, флаг устойчивости |
| `crisis-episodes.csv` | глубина (%) и время восстановления (лет, `NA` = не восстановилась к 2024 г.) по 4 эпизодам |
| `retro-check.csv` | rho Спирмена (2005 → 2005–2024) по каждому индикатору и композиту 2005 г. |

**Правила и пороги:** методика — `docs/economic-strength/1-foundations/1.0-A-strength-index.md`, разделы 3.1–3.4; паспорта рядов — `passports.md` в этой папке.

**Исключения и оговорки:**
- Тайвань отсутствует в WDI — в v1 добавляется по IMF WEO/ADB.
- Венесуэла исключена из композита (данных меньше порога «7 входов из 10»).
- В пилотной версии не используются `tfp_pwt` (PWT, до 2019 г.) и `eci_atlas` (Harvard Atlas) — v1.
- Смешение опорных годов не возникало: все ряды покрывают 2024 г. не менее чем по 26 странам (проверяется на каждом запуске).
