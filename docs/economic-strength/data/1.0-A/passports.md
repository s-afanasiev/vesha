# Паспорта рядов — 1.0-A «Методика индекса силы экономики»

12 кандидатных рядов по четырём измерениям (план 0.2). В пилотном расчёте v0.1 используются 10 (8 рядов WDI + 2 расчётных); ряды `tfp_pwt` и `eci_atlas` включены в паспорта и предназначены для версии v1 (см. «ограничения»). Обязательные поля — по стандарту 4.2, п. 3.C.1. Все ряды загрузки 2026-10-18.
