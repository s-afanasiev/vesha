# 1.1-F. Цена капитала — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.1-F/wacc-cutoff.mjs
```

**Что делает скрипт:**

1. Скачивает дневной ряд ключевой ставки ЦБ РФ (с 17.09.2013), считает годовые средние; сырьё — `data/economic-strength/1.1-F/raw/`.
2. Скачивает кривую доходности ОФЗ ЦБ (последняя доступная дата) и берёт точку 10 лет.
3. Скачивает 10-летние госдоходности из FRED (США, Германия, Корея, Россия-до-2018; TR/BR/CN недоступны — 404), считает годовые средние.
4. Скачивает таблицу страновых премий Damodaran (спред, CRP, ERP, налог).
5. Скачивает WDI: ставки по кредитам/депозитам, реальная ставка, инфляция (7 стран, 2010–2024).
6. Скачивает условия займов ФРП (`frprf.ru/zaymy`) и сохраняет ключевой фрагмент.
7. Считает WACC панели (валютная рамка Дамодарана) и разложение рублёвой цены денег России (2024).
8. Считает максимальный срок окупаемости (NPV = 0) при ставке r и маржинальности m и IRR типовых профилей проектов с фильтром 10/18/25 %.

**Параметры модели** (wE, wD, β, налог, профили проектов) собраны в блоке `PARAMS`/`PROJECT_CLASSES` в начале скрипта — правятся в одном месте.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `keyrate-daily.csv` / `keyrate-annual.csv` | Ключевая ставка: день (3281) и годовые средние (2013–2026) |
| `ofz-curve-latest.csv` | Кривая ОФЗ на последнюю доступную дату (16.10.2026) |
| `wacc-panel.csv` | WACC панели 2024 (валютная рамка): Rf, спред, CRP, ERP, Ke, WACC, локальная ставка |
| `russia-cost-of-capital.csv` | Россия 2010–2024: ключевая, кредит, депозит, реальная ставка, инфляция |
| `russia-ruble-decomposition.csv` | Разложение рублёвой цены денег 2024 (в т.ч. модельные Ke/WACC) |
| `payback-cutoff.csv` | Срок окупаемости (NPV = 0): ставки 10/18/25 % × маржинальность 15–50 % |
| `project-classes-cutoff.csv` | IRR классов проектов и прохождение фильтра 10/18/25 % |
| `damodaran-crp.csv` | Страновые премии по 7 странам (февраль 2026) |
| `frp-facts.txt` | Фрагмент условий ФРП (выгрузка) |

**Оговорки:**
- Исторический ряд доходности ОФЗ сайтом ЦБ не отдаётся (проверено: параметр даты игнорируется) — в наличии только последняя кривая; исторический ряд — ручной сбор (v1).
- FRED: серии 10-летних доходностей Турции/Бразилии/Китая недоступны (404); Россия — только до 2018 г.
- В таблице Damodaran налог для России искажён (8,14 % = дубль ERP) — в модели используется ставка НК РФ (20 % за 2024 г.; с 2025 г. — 25 %).
- Структура инвестиций по источникам (Росстат) и портфель ФРП/КИП — не собраны: сайт Росстата недоступен из среды, ведомственные портфели — ручной сбор (v1).
- Профили проектов в шаге 9 — модельные допущения [О], а не данные.
