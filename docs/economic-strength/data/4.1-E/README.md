# Данные документа 4.1-E — короткий список кандидатов

Расчёт к документу [4.1-E](../../4-method/4.1-E-candidates.md). Формула — общий модуль [`../4.1-A/isc.mjs`](../4.1-A/isc.mjs) (документ 4.1-A, v0.2).

```bash
node docs/economic-strength/data/4.1-E/t-model.mjs --write
node docs/economic-strength/data/4.1-A/score.mjs --dir docs/economic-strength/data/4.1-E
node docs/economic-strength/data/4.1-E/sensitivity.mjs
```

| Файл | Что внутри |
|---|---|
| `products.csv` | 11 кандидатов: код карточки, название, класс, свой ли продукт, есть ли полевой замер, описание |
| `pilot-a.csv` | параметры оценки с опорой на данные рынка; обоснование и ссылки на факты — в `note` и в карточках |
| `results-a.csv` | выход score.mjs: баллы, V, R, ИСЦП в двух перспективах, Δ, квадрант, интервал, устойчивость |
| `payback.csv` | сценарии окупаемости (v0.3): цена за единицу, единиц у клиента, разовые платежи и затраты, переменные затраты, отток, клиенты целевого масштаба `n3`; обоснование — в `note` |
| `t-model.mjs` | срок окупаемости T по общей модели [`../4.1-A/payback.mjs`](../4.1-A/payback.mjs); `--write` записывает t_min, t_mode, t_max в `pilot-a.csv`; печатает, сколько клиентов в месяц и какая цена нужны для окупаемости за 22 месяца |
| `sensitivity.mjs` | торнадо по параметрам и переломные значения: при каком значении одного параметра кандидат догоняет лидера |

Столбцы `pilot-a.csv` — как в [`../4.1-A/README.md`](../4.1-A/README.md). Параметры — экспертные оценки [Э] с опорой на открытые данные [Ф]; уровень источника — 5–6 (сайты вендоров, обзоры) по стандарту 4.2, 3.C.2.
