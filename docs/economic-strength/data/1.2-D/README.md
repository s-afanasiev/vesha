# 1.2-D. Воронка STEM — README

**Команда запуска** (из корня репозитория; Python ≥ 3.10, `pypdf`; нужен доступ к сети):

```
pip install pypdf
python docs/economic-strength/data/1.2-D/ege-collect.py
python docs/economic-strength/data/1.2-D/context-collect.py
```

**Что делает `ege-collect.py`:**

1. Скачивает 21 PDF методических рекомендаций ФИПИ 2019–2025 гг. (физика, профильная математика, информатика) в `data/economic-strength/1.2-D/raw/fipi/` (вне git).
2. Сверяет 33 контрольных значения (участники, средние баллы), изъятых вручную из этих PDF, с текстом первоисточников и печатает ✓/✗ по каждому.
3. Собирает `ege-stem-2015-2025.csv` (33 строки) из выверенной таблицы.

**Что делает `context-collect.py`:** сеть не нужна — скрипт фиксирует выверенные (собранные вручную на шаге S3) значения трёх контекстных CSV: `msi-russia-2015-2025.csv` (PISA/TIMSS/PIRLS), `teachers-2024.csv` (кадры учителей), `dop-education-2024.csv` (сети допобразования, олимпиадное движение, профильные классы). У каждой строки — источник, статус и примечание; URL — в разделе «Источники» документа 1.2-D.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `ege-stem-2015-2025.csv` | Участники (тыс. чел.) и средние тестовые баллы ЕГЭ по трём предметам, 2015–2025; по каждой строке — источник, статус и примечание |
| `msi-russia-2015-2025.csv` | Международные оценки: PISA-2015/2018, TIMSS-2015/2019, PIRLS-2016/2021 + строки «не участвовала» (PISA-2022/2025, TIMSS-2023) |
| `teachers-2024.csv` | Кадры: дефицит и возраст учителей (в т.ч. по предметам), опросы родителей, прогнозы РАНХиГС |
| `dop-education-2024.csv` | «Кванториумы», «IT-кубы», «Сириус», охват допобразованием, ВОШ и международные олимпиады, профильные классы |
| `passports.md` | Паспорта рядов (стандарт 4.2) |
| `ege-collect.py` | Загрузка PDF ФИПИ, контрольные сверки, сборка CSV |
| `context-collect.py` | Сборка трёх контекстных CSV (S3; без сети) |

Колонки CSV: `год;предмет;участников_тыс;средний_балл;источник;статус;примечание`. Статусы: «собрано», «частично» (одно из двух значений), «искали, не нашли».

**Источники и иерархия** (полные URL — в разделе «Источники» документа 1.2-D и в `SOURCE`-строках скрипта):

1. **ФИПИ, методические рекомендации** по итогам ЕГЭ, 2019–2025 (`doc.fipi.ru/ege/analiticheskie-i-metodicheskie-materialy/<год>/…`) — первичный источник. Дают число участников года и (не всегда) средний балл; в отчётах 2020–2024 гг. есть таблицы средних баллов за три года.
2. **Рособрнадзор, пресс-материалы** (`obrnadzor.gov.ru/news/…`, пресс-релиз 22.06.2021) — средние баллы и участники по математике и физике за 2021 г., определение совокупности участников (2019 г.).
3. **Вторичные сводки** (помечены в CSV): «Ланцман-2023» (Мел, со ссылкой на Рособрнадзор) — средние баллы 2019–2023 и участники; «Итоги-2024» (Вузопедия, сводка данных Рособрнадзора); «Итоги-2025» (4ЕГЭ, сводка данных Рособрнадзора).

**Источники контекстных рядов S3** (собраны вручную 19–20.10.2026; полные URL — в разделе «Источники» документа):

4. **Международные оценки:** пресс-релиз Минпросвещения о TIMSS-2019 (`edu.gov.ru/press/3231/…`); справка CICED о PISA-2018 (`ciced.ined.ru/…`, волны 2015 и 2018); места России в PISA-2018 — РБК (03.12.2019) и DW; таблица участия стран в PISA — NCES (`nces.ed.gov/surveys/pisa/participation.asp`); PIRLS-2021 — обзор результатов (skillbox, 18.05.2023); отказ от TIMSS-2023 — Forbes/РБК/«Ведомости» (16–17.03.2023). Первичные сайты IEA и OECD недоступны (таймаут), микро-данные не использовались.
5. **Кадры:** «Учительская газета» (данные опроса ФСО 2024 г. и выступления В. Путина); EdDesign Mag (разбор данных Минпросвещения, 2025); «Независимая газета» (30.07.2025 — оценки Минпросвещения и РАНХиГС); сводка «Минпросвещения России. Итоги 2024 года» (27.12.2024, публикация Минобра Пензенской области).
6. **Допобразование и олимпиады:** сводка «Минпросвещения России. Итоги 2024 года»; архив материалов нацпроекта «Образование» («Национальныепроекты.рф»); `sochisirius.ru` и Siriusmag; данные правительства о ВОШ-2024/25 (через `d-russia.ru`), `mos.ru`.

**Методические оговорки:**

- **Участники — все сдававшие экзамен** (выпускники текущего года + прошлых лет + резервные дни), а не только выпускники 11 классов. Пример: физика-2019 — 149 400 чел. по ФИПИ против 139 тыс. выпускников 11 класса в пресс-релизе Рособрнадзора. Ряд `ege_choices` (доля от выпускников) требует знаменателя: собрана точечная оценка ~635 тыс. выпускников 11-х классов (2024, вторичный источник); полного ряда нет.
- **Значения расходятся между отчётами разных лет** (основной период / все периоды / перепроверки). Пример: физика-2019 — 142 607 (отчёт 2020 г.), 149 400 (отчёт 2019 г.), 152 493 (отчёт 2021 г.). В CSV — значение отчёта соответствующего года, альтернативы — в примечании.
- **Профильная математика:** участники 2015–2020 гг. не собраны (в рекомендациях ФИПИ их нет, во вторичных сводках — другая совокупность: 362–421 тыс. без ясного определения); ряд участников начинается с 2021 г.
- **2015–2017 гг.:** рекомендации ФИПИ в открытом доступе начинаются с 2019 г.; архив 2015–2018 не найден (страница ФИПИ — 403, Wayback недоступен). Участники физики-2017 и информатики-2017 — из ретроспективы ФИПИ-2019.
- **2018 г.:** у математики — только средний балл, у информатики — только участники.
- **Вторичные сводки расходятся с ФИПИ:** информатика-2025 — 55,8 (ФИПИ) против 57,77 (4ЕГЭ); физика-2025 — 61,3 против 61,66; физика-2023 — 54,62 против 54,95; математика-2019 — 55,91 против 56,5. Приоритет — ФИПИ/официальный пресс-релиз, альтернатива — в примечании.
- **Средние баллы несопоставимы между годами** при изменении шкал, КИМ и состава участников; ряд не является индексом качества образования.
- **`ege.hse.ru/stata`** — мониторинг качества приёма в вузы, предметной статистики ЕГЭ не содержит (проверено 2026-10-19); для рядов не использовался, применяется в 1.2-B.
- **2024–2025 гг.** частично опираются на вторичные сводки (математика-2024/2025 — только они; физика/информатика проверяются по ФИПИ).
- **Контекстные ряды (S3) — ручной сбор из публичных публикаций**, не из первичных микро-данных: официальные таблицы Росстата/ОО-1 по кадрам и регионам не выгружались; первичные данные IEA/OECD недоступны. Статусы строк — «собрано» / «частично».
- **Кадровые оценки расходятся:** официальный дефицит — 1,7–1,8 % (~18–19 тыс. вакансий), альтернативная оценка «при одной ставке на учителя» — ~470 тыс. (31 %); в CSV обе версии с пометками.
- **Международные сравнения заморожены:** последние волны с участием России — PISA-2018, TIMSS-2019, PIRLS-2021; PISA-2022/2025 и TIMSS-2023 — без России.
- **Региональный разрез ЕГЭ:** полный порегиональный ряд средних баллов в открытом доступе не найден (не публикуется); в документе — только фрагменты (лидеры по сводкам 2024 г., мониторинг приёма ВШЭ).
- **Знаменатель выпускников 11 классов:** точечная оценка ~635 тыс. (2024, со ссылкой на выступление вице-премьера в публикациях); официальные таблицы Росстата не выгружались, доли от выпускников в документе — верхние оценки.
