# 1.2-D. Воронка STEM — README

**Команда запуска** (из корня репозитория; Python ≥ 3.10, `pypdf`; нужен доступ к сети):

```
pip install pypdf
python docs/economic-strength/data/1.2-D/ege-collect.py
```

**Что делает `ege-collect.py`:**

1. Скачивает 21 PDF методических рекомендаций ФИПИ 2019–2025 гг. (физика, профильная математика, информатика) в `data/economic-strength/1.2-D/raw/fipi/` (вне git).
2. Сверяет 33 контрольных значения (участники, средние баллы), изъятых вручную из этих PDF, с текстом первоисточников и печатает ✓/✗ по каждому.
3. Собирает `ege-stem-2015-2025.csv` (33 строки) из выверенной таблицы.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `ege-stem-2015-2025.csv` | Участники (тыс. чел.) и средние тестовые баллы ЕГЭ по трём предметам, 2015–2025; по каждой строке — источник, статус и примечание |
| `passports.md` | Паспорта рядов (стандарт 4.2) |
| `ege-collect.py` | Загрузка PDF ФИПИ, контрольные сверки, сборка CSV |

Колонки CSV: `год;предмет;участников_тыс;средний_балл;источник;статус;примечание`. Статусы: «собрано», «частично» (одно из двух значений), «искали, не нашли».

**Источники и иерархия** (полные URL — в разделе «Источники» документа 1.2-D и в `SOURCE`-строках скрипта):

1. **ФИПИ, методические рекомендации** по итогам ЕГЭ, 2019–2025 (`doc.fipi.ru/ege/analiticheskie-i-metodicheskie-materialy/<год>/…`) — первичный источник. Дают число участников года и (не всегда) средний балл; в отчётах 2020–2024 гг. есть таблицы средних баллов за три года.
2. **Рособрнадзор, пресс-материалы** (`obrnadzor.gov.ru/news/…`, пресс-релиз 22.06.2021) — средние баллы и участники по математике и физике за 2021 г., определение совокупности участников (2019 г.).
3. **Вторичные сводки** (помечены в CSV): «Ланцман-2023» (Мел, со ссылкой на Рособрнадзор) — средние баллы 2019–2023 и участники; «Итоги-2024» (Вузопедия, сводка данных Рособрнадзора); «Итоги-2025» (4ЕГЭ, сводка данных Рособрнадзора).

**Методические оговорки:**

- **Участники — все сдававшие экзамен** (выпускники текущего года + прошлых лет + резервные дни), а не только выпускники 11 классов. Пример: физика-2019 — 149 400 чел. по ФИПИ против 139 тыс. выпускников 11 класса в пресс-релизе Рособрнадзора. Ряд `ege_choices` (доля от выпускников) требует знаменателя — он собирается на шаге S3.
- **Значения расходятся между отчётами разных лет** (основной период / все периоды / перепроверки). Пример: физика-2019 — 142 607 (отчёт 2020 г.), 149 400 (отчёт 2019 г.), 152 493 (отчёт 2021 г.). В CSV — значение отчёта соответствующего года, альтернативы — в примечании.
- **Профильная математика:** участники 2015–2020 гг. не собраны (в рекомендациях ФИПИ их нет, во вторичных сводках — другая совокупность: 362–421 тыс. без ясного определения); ряд участников начинается с 2021 г.
- **2015–2017 гг.:** рекомендации ФИПИ в открытом доступе начинаются с 2019 г.; архив 2015–2018 не найден (страница ФИПИ — 403, Wayback недоступен). Участники физики-2017 и информатики-2017 — из ретроспективы ФИПИ-2019.
- **2018 г.:** у математики — только средний балл, у информатики — только участники.
- **Вторичные сводки расходятся с ФИПИ:** информатика-2025 — 55,8 (ФИПИ) против 57,77 (4ЕГЭ); физика-2025 — 61,3 против 61,66; физика-2023 — 54,62 против 54,95; математика-2019 — 55,91 против 56,5. Приоритет — ФИПИ/официальный пресс-релиз, альтернатива — в примечании.
- **Средние баллы несопоставимы между годами** при изменении шкал, КИМ и состава участников; ряд не является индексом качества образования.
- **`ege.hse.ru/stata`** — мониторинг качества приёма в вузы, предметной статистики ЕГЭ не содержит (проверено 2026-10-19); для рядов не использовался, применяется в 1.2-B.
- **2024–2025 гг.** частично опираются на вторичные сводки (математика-2024/2025 — только они; физика/информатика проверяются по ФИПИ).
