# 1.1-Σ. Институциональный профиль — README

Сводная записка `1.1-sum-institutions.md` (тип W) не создаёт новых рядов: она сшивает результаты шести документов направления 1.1 (A–F). Данные и код — в соответствующих папках:

| Документ | Папка данных | Ключевые артефакты |
|---|---|---|
| 1.1-A | `data/1.1-A/` | ПИИ/инвестквота панели, оценки собственности |
| 1.1-B | `data/1.1-B/` | Паспорта-статусы (правовые ряды недоступны) |
| 1.1-C | `data/1.1-C/` | Патентная активность, НИОКР, исследователи |
| 1.1-D | `data/1.1-D/` | EPU-ряд 1994–2026, ИРВ, корреляции с инвестквотой |
| 1.1-E | `data/1.1-E/` | Enterprise Surveys (рента), каркас красных флагов |
| 1.1-F | `data/1.1-F/` | Ключевая ставка, ОФЗ, WACC панели, отсечение проектов |

В этой папке:

| Файл | Содержание |
|---|---|
| `key-metrics.csv` | Сводная матрица ключевых чисел всех шести документов (только значения, проверенные в 1.1-A…F) |

Правило пополнения: новое число попадает в `key-metrics.csv` только после того, как оно появилось в исходном документе направления.
