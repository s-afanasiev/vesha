# Паспорта рядов — 1.2-C «Рабочие руки»

Поля — по стандарту 4.2 (п. 3.C.1). Доступность источников проверена 2026-10-19; статусы указаны по каждой серии.

- **`spo1` — Форма № СПО-1: приём, численность и выпуск по профессиям и специальностям СПО (2024/25).** Единица: чел. Частота и охват: год; Россия; профессии/специальности, база 9/11 классов, ГОС/НЕГОС, формы обучения. Источник: Минпросвещения России (ведомственная отчётность ФСН, уровень 1/2), `docs.edu.gov.ru`, документ 2488e3f2…, файл 7126 (31,3 МБ). Метод: разбор `СВОД_СПО1_ВСЕГО.xls` скриптом `spo1-professions.py` (листы `Р2_1_1` — приём, `Р2_1_2` — численность по курсам, `Р2_1_3(1)` — выпуск фактический, `Р2_3` — целевое обучение). **Статус: разобрано (S2). Итоги: приём 1 263 999 (специалисты 1 044 504 + рабочие 219 495); выпуск фактический 2023/24 — 851 619 (688 009 + 163 610); по 5 профессиям — приём 42 342, выпуск 24 903.** Ограничения: свод — агрегат РФ; выпуск — фактический с 01.10 по 30.09; перечни профессий менялись (15.01.38 и 08.01.31 введены после 2021 г.); приём/выпуск — без иностранных граждан; коды агрегируются вручную.
- **`spo1_2021` — Форма № СПО-1 за 2021/22 (для динамики приём/выпуск).** Единица: чел. Частота: год; Россия. Источник: `docs.edu.gov.ru`, документ 018f742a…, файл 4445 (32,9 МБ). Метод: тот же скрипт `spo1-professions.py` (структура листов и колонок совпадает). **Статус: разобрано (S2). Итоги: приём 1 077 837 (870 906 + 206 931); выпуск 2020/21 — 731 886 (573 781 + 158 105).** Ограничения: те же; старые перечни профессий; колонки демоэкзамена заполнены частично (2021 — 2 446 по коду 15.01.05).
- **`spo1_professions` — Ряды по пяти профессиям: наладчик ЧПУ, сварщик, электромонтажник, слесарь-ремонтник, оператор линии.** Единица: чел., %. Частота: год; Россия; 2021 и 2024. Источник: расчёт по `spo1`/`spo1_2021` (CSV `spo1-five-professions-2021-2024.csv`). Метод: суммирование кодов 15.01.23+15.01.38 (наладчик), 15.01.05 (сварщик), 08.01.18+08.01.31 (электромонтажник), 15.01.35 (слесарь-ремонтник), 15.01.32+35.01.04 (оператор) по строкам «на базе 9/11 классов». **Статус: собрано (S2): приём пяти 31 075 → 42 342 (+36,3 %); выпуск 21 087 → 24 903 (+18,1 %); ГИА-демо 2024 — 55,8–96,9 %.** Ограничения: 15.01.35 в перечне называется «Мастер слесарных работ» (прямого кода «слесарь-ремонтник» нет); 15.01.38 в 2021 г. отсутствовал; суммы по кодам проверялись по строкам разделов.
- **`demo_exam` — Демонстрационный экзамен СПО.** Единица: %, чел. Частота: год; Россия; 2024–2025. Источник: Минпросвещения России, пресс-релиз 17.03.2026 (`edu.gov.ru/press/11191`). Метод: ручной сбор. **Статус: собрано (S1/S3): 2025 — 56,02 % успешно прошли профильный уровень, ~540 тыс. участников; ГИА в формате демоэкзамена — 62,27 %; базовый уровень — 43,9 %; 2024 — более 364 тыс. участников, 54,8 % — профильный уровень.** Ограничения: 56,02 % — официальная формулировка (доля обучающихся, успешно прошедших профильный уровень), а не доля участников; независимая оценка квалификации не внедрена.
- **`professionalitet` — Программа «Профессионалитет»: кластеры, партнёры, студенты.** Единица: шт., чел. Частота: год; Россия; 2022–2026. Источник: Минпросвещения России, пресс-релиз 16.02.2026 (`edu.gov.ru/press/11039`). Метод: ручной сбор. **Статус: собрано (S3): 506 кластеров в 86 регионах, 24 отрасли, 323 образовательно-производственных кластера; 2 500+ партнёров; 4 000+ лабораторий; 97 тыс. целевых договоров с 2022 г.; ~290 тыс. первокурсников (22,3 % от ~1,3 млн); 63 % девятиклассников — в колледж; цель 1 млн рабочих к 2028 г.** Ограничения: данные ведомственные; независимой оценки трудоустройства выпускников нет.
- **`wages_groups` — Средняя начисленная зарплата по профессиональным группам (Росстат).** Единица: руб./мес. Частота: раз в два года (октябрь); Россия; 2015–2025. Источник: Росстат, `sr-zpl6_2025.xlsx` (`rosstat.gov.ru/storage/mediabank/sr-zpl6_2025.xlsx`). Метод: разбор `market-proxies.py`. **Статус: собрано (S2): квалифицированные рабочие промышленности 51 733 (2021) → 98 120 (2025), +89,7 %; торговля/услуги 35 399 → 59 516, +68,1 %; все работники 57 240 → 97 179, +69,8 %.** Ограничения: группа занятий, а не профессия; номинал; обследование октябрьское, выборочное; 57-Т по профессиям не публикуется.
- **`labor_survey` — ОРС и форма 57-Т: занятость и зарплаты по профессиям.** Единица: чел., руб. Частота: год/квартал; Россия; 2017–2025. Источник: Росстат (профессиональный разрез в открытых публикациях отсутствует). Метод: поиск — S1–S2. **Статус: искали, не нашли (профессиональный разрез); прокси — `wages_groups`.** Ограничения: ОКПДТР и группировки менялись; 57-Т публикуется только агрегированно.
- **`vacancies` — Вакансии по пяти профессиям (hh.ru).** Единица: шт. Частота: разовый снимок; Россия; 2026-10-19. Источник: hh.ru, поиск по названию вакансии (API отдаёт 403, использован HTML). Метод: `market-proxies.py`. **Статус: собрано (S2): наладчик ЧПУ 653, сварщик 13 213, электромонтажник 27 621, слесарь-ремонтник 7 241, оператор линии 3 305; отношение вакансий к выпуску 0,7–16,7.** Ограничения: без дедупликации, поиск по подстроке, разовый снимок; исторических рядов 2021 vs 2025 нет; вакансии ≠ дефицит.
- **`dual_cases` — Дуальные модели Германии и Швейцарии.** Единица: %, чел. Частота: разовый срез; 2024–2025. Источники: OECD/BIBB/EC Monitor (Германия), SBFI/OECD (Швейцария). Метод: ручной сбор (S3). **Статус: собрано (S3): Германия — 88 % VET-учащихся в дуальных программах, 475 950 новых контрактов (2025), 54 400 мест не заполнено при 84 400 ищущих, занятость выпускников 92,2 % (2024); Швейцария — ~2/3 когорты в VET, ~260 профессий.** Ограничения: уровни образования различаются (верхняя ступень среднего vs СПО); прямой перенос на РФ невозможен; занятость по Швейцарии не сопоставима.
