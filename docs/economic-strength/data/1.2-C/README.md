# 1.2-C. Рабочие руки — README

**Команда запуска** (из корня репозитория; Python ≥ 3.10; нужен доступ к сети):

```
pip install xlrd openpyxl
python docs/economic-strength/data/1.2-C/spo1-professions.py
python docs/economic-strength/data/1.2-C/market-proxies.py
```

**Что делает `spo1-professions.py`:**

1. Скачивает два архива СПО-1 с `docs.edu.gov.ru` в `data/economic-strength/1.2-C/raw/` (вне git): 2021/22 (документ `018f742a…`, файл 4445) и 2024/25 (документ `2488e3f2…`, файл 7126); имена в архивах — CP866 (декодируются).
2. Распаковывает главный свод `СВОД_СПО1_ВСЕГО.xls` каждого года.
3. Разбирает листы `Р2_1_1` (приём 2021/2024) и `Р2_1_3(1)` (выпуск фактический 2020/21 и 2023/24): итоги по программам специалистов среднего звена и квалифицированных рабочих, служащих.
4. Суммирует пять профессий по кодам: наладчик ЧПУ (15.01.23 + 15.01.38), сварщик (15.01.05), электромонтажник (08.01.18 + 08.01.31), слесарь-ремонтник (15.01.35), оператор линии (15.01.32 + 35.01.04) — приём, выпуск, ГИА в форме демоэкзамена, целевой выпуск.

**Что делает `market-proxies.py`:**

1. Скачивает `sr-zpl6_2025.xlsx` Росстата («Средняя начисленная заработная плата работников по профессиональным группам», октябрь 2015–2025) в `data/economic-strength/1.2-C/raw/rosstat/`; для `rosstat.gov.ru` обходится ошибка цепочки сертификатов (`ssl._create_unverified_context`).
2. Строит ряд по группам занятий с ростом 2021 → 2025 (номинал).
3. Делает снимок вакансий hh.ru по пяти профессиям (поиск по названию, Россия) и считает отношение «вакансий на выпускника» по данным СПО-1.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `spo1-five-professions-2021-2024.csv` | 5 профессий: приём/выпуск 2021 и 2024, Δ, доля ГИА-демо и целевых 2024 |
| `spo1-totals-2021-2024.csv` | Итоги СПО-1 по программам специалистов и рабочих за оба года |
| `rosstat-wages-groups.csv` | Зарплаты по профессиональным группам: 2021/2023/2025 и рост |
| `hh-vacancies-2026.csv` | Снимок вакансий hh.ru (2026-10-19) по 5 профессиям и вакансий на выпускника |
| `passports.md` | Паспорта рядов `spo1`, `spo1_2021`, `spo1_professions`, `demo_exam`, `professionalitet`, `wages_groups`, `labor_survey`, `vacancies`, `dual_cases` |

Промежуточные архивы и распакованные своды — в `data/economic-strength/1.2-C/raw/` (вне git).

**Оговорки:**

- Приём и выпуск СПО — разные когорты; их нельзя вычитать друг из друга.
- Перечни профессий менялись: 15.01.38 «Оператор-наладчик металлообрабатывающих станков» и 08.01.31 введены после 2021 г.; в 2021 г. выпуска по ним нет. 15.01.35 в перечне 2022 г. называется «Мастер слесарных работ»; прямого кода «слесарь-ремонтник» нет.
- «Выпуск» — фактический с 01.10 по 30.09; включает выпускников прошлых лет приёма и не совпадает с приёмом того же года.
- Вакансии hh.ru — разовый снимок без дедупликации; поиск по названию может включать смежные профессии; это не официальный дефицит.
- Зарплаты Росстата — по группам занятий (квалифицированные рабочие промышленности и т. п.), а не по пяти профессиям; номинал не очищен от инфляции.
- Профессиональный разрез ОРС/57-Т и трудоустройство выпускников СПО в открытых данных отсутствуют: статусы «искали, не нашли» зафиксированы в паспортах.
