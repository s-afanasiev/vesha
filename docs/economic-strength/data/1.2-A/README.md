# 1.2-A. Исследовательский корпус — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.2-A/research-workforce.mjs
```

**Что делает скрипт:**

1. OpenAlex: счёт работ с российским авторством по годам (`group_by=publication_year`) и работ с международным соавторством (`countries_distinct_count>1`); считает долю кооперации; сырьё — `data/economic-strength/1.2-A/raw/`.
2. OpenAlex: распределение по полям науки (`primary_topic.field.id`) за 2021 и 2024 гг.
3. WDI: исследователи на млн человек (`SP.POP.SCIE.RD.P6`) и численность (`SP.POP.SCIE.RD`, для России пусто) по 7 странам.
4. UNESCO UIS: определения индикаторов исследователей (секторные данные — не отдались).

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `openalex-ru-publications.csv` | Годы 2010–2026: работы всего, международные, доля % (2026 — неполный) |
| `openalex-ru-fields.csv` | Поля науки 2021 и 2024: число работ |
| `wdi-researchers.csv` | Исследователи: 7 стран, 2010–2024 (для РФ — на млн; абс. численность недоступна) |

**Оговорки:**
- OpenAlex — открытая база (препринты, конференции); сравнение с Scopus/WoS напрямую некорректно.
- 2026 г. неполный — не интерпретировать как обвал.
- Возраст исследователей, структура финансирования (ИСИЭЗ, РНФ) и патентные ссылки — ручной сбор (v1), см. паспорта.
