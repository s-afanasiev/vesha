# 1.2-B. Инженерная воронка — README

**Команда запуска** (из корня репозитория; Python ≥ 3.10; нужен доступ к сети):

```
pip install xlrd openpyxl
python docs/economic-strength/data/1.2-B/engineering-funnel.py --capitals
```

Второй скрипт — оснащённость по форме ВПО-2 (2025):

```
python docs/economic-strength/data/1.2-B/vpo2-software.py
```

Режимы `engineering-funnel.py`:

- без флагов — только главные своды (`СВОД_ВПО1_ВСЕГО`) за 2020–2025 гг.;
- `--capitals` — дополнительно региональные файлы Москвы и Санкт-Петербурга (ГОС/НЕГОС × очная/очно-заочная/заочная) и файлы `engineering-capitals-<год>.csv`;
- `--years 2024,2025` — ограничить годы;
- `--census` — диагностика: список листов и структуры в архивах (без сборки CSV).

**Что делает скрипт:**

1. Скачивает архивы ВПО-1 с `minobrnauki.gov.ru/action/stat/highed/` в `data/economic-strength/1.2-B/raw/` (вне git); 2022 г. — zip-в-zip.
2. Распаковывает главный свод (2020–2024 — `.xls`, 2025 — `.xlsx`) и, с `--capitals`, региональные файлы столиц; имена в архивах — CP866 (декодируются).
3. Разбирает листы `2.1.1` (приём, колонка «Принято — всего»), `2.1.2(1)` (численность 1-го и 2-го курсов), `2.1.3` (выпуск фактический); суммирует по УГСН (первые две цифры кода направления).
4. Группы: 09 «ИТ и вычислительная техника», 15 «Машиностроение», 11 «Электроника и радиотехника», 13 «Электро- и теплоэнергетика», 04 «Химия», 18 «Химические технологии».
5. Строит когорты «приём → выпуск» (бакалавриат 2020→2024 и 2021→2025; специалитет 2020→2025; магистратура 2022→2024 и 2023→2025) и переходы «1-й → 2-й курс» (2020–2025).

**Что делает `vpo2-software.py`:**

1. Скачивает архив «Своды ВПО-2 за 2025 г.» (~16 МБ) в `data/economic-strength/1.2-B/raw/` и распаковывает 83 региональных свода `*_ВСЕГО.xlsx` + выходную таблицу `tab19.xlsx`.
2. Суммирует по России подраздел 2.1 (персональные компьютеры: всего / учебного назначения / доступные в свободное время / поступившие за год / ноутбуки / планшеты), 2.2 (число организаций с каждым типом специального ПО) и 2.3 (максимальная скорость Интернета).
3. Берёт численность студентов ВО из `tab19` и считает ПК на 100 студентов, долю обновления парка.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `engineering-funnel.csv` | 120 строк: когорты (приём → выпуск, потери в чел. и %) и переходы 1→2 курс по 6 группам УГСН |
| `engineering-capitals-<год>.csv` | Россия / Москва / Санкт-Петербург / прочие регионы: приём и выпуск по 3 уровням × 6 группам (2020–2025) |
| `vpo2-osnashchennost.csv` | 42 показателя оснащённости за 2025 г.: парк ПК, специальное ПО, скорость Интернета, нормировка на студентов |
| `passports.md` | Паспорта рядов `vpo1`, `vpo1_capitals`, `engineering_funnel`, `vpo2`, `vpo2_osnashchennost` и др. |

Промежуточные `parse-<год>.json` (проверка колонок и листов) и архивы — в `data/economic-strength/1.2-B/raw/` (вне git).

**Оговорки:**

- «Потери» — балансовый разрыв «приём → выпуск», а не чистый отсев: включает переводы, восстановления, академические отпуска и несовпадение сроков (заочная магистратура — 2,5 года).
- 2020 г.: приём разобран по листу `2.1.1` главного свода; численность 1-го курса может на ~2 % превышать приём из-за переводов.
- Своды — агрегат РФ и региональные срезы; уровня отдельного вуза в архивах нет (поуровневый разрыв «топ-вузы vs региональные» — v1).
- Приём и численность — без иностранных граждан (оговорка формы).
- «Выпуск → работа по специальности» в архивах отсутствует: портал `vo.graduate.edu.ru` недоступен (2026-10-19), статус — «искали, не нашли».
- ВПО-2 не содержит графы «доля обучения на актуальном оборудовании/ПО» и учёта отечественных САПР/ПЛК; счётчики ПО — число отчитывающихся единиц (включая филиалы), а не студентов; знаменатель 1 236 — нижняя оценка (максимум по категориям Р2_2).
