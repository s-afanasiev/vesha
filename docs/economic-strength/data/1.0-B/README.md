# 1.0-B. Панель «Индикаторы силы экономики» — README

**Команда проверки** (из корня репозитория; Node ≥ 20):

```
node docs/economic-strength/data/1.0-B/validate-panel.mjs
```

## Состав папки

| Файл/папка | Назначение |
|---|---|
| `passports.md` | 54 паспорта рядов по стандарту 4.2 (п. 3.C.1): id, единица, частота и охват, источник, адрес, дата, уровень, метод, ограничения, версия, условия |
| `panel-v1.csv` | машиночитаемый реестр рядов (54 строки): id, группа, название, единица, частота, покрытие, источник, уровень (1–6), адрес, статус замещения |
| `series/` | выгруженные серии: `<id>_<ГГГГ-ММ-ДД>.csv` с колонками `year;value` (разделитель `;`, UTF-8 с BOM) |
| `validate-panel.mjs` | автоматическая проверка (см. ниже) |
| `data/economic-strength/1.0-B/raw/` (в корне репозитория, вне git) | сырые выгрузки API с датой в имени файла |

## Что проверяет `validate-panel.mjs`

1. **Структура CSV:** точная шапка, 54 строки, уникальные id, все поля заполнены, уровень — целое 1–6, частота и покрытие — из словаря, статус замещения — из словаря 3.2.
2. **Согласованность трёх мест:** списки id в `panel-v1.csv`, `passports.md` и реестре документа (`1-foundations/1.0-B-indicators-panel.md`, подразделы 3.1 и 3.4) совпадают; каждый id в документе встречается не меньше двух раз.
3. **Числовые проверки серий** (когда в `series/` появятся файлы): пропуски лет; скачки годовых изменений больше 3σ — предупреждения с указанием года.
4. Ошибки блокируют выпуск (код возврата 1), предупреждения — нет.

## Как добавить ряд данных

1. Выгрузить серию из источника (адрес — в паспорте) и сохранить как `series/<id>_<ГГГГ-ММ-ДД>.csv` с шапкой `year;value` (дата в имени = дата выгрузки).
2. Сырую выгрузку положить в `data/economic-strength/1.0-B/raw/` (вне git, чтобы репозиторий не пухнул).
3. Если изменился уровень источника, метод или ограничения — обновить паспорт и записать новую версию.
4. Запустить `validate-panel.mjs`; устранить ошибки; предупреждения о скачках — объяснить в тексте документа-потребителя (например, разрыв методики).
5. Для рядов из таблицы замещения (3.2 документа) значения хранятся как интервал, разметка — `[О]`, никогда как факт.
