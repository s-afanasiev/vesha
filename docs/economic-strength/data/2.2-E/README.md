# Данные документа 2.2-E — эффект и цена мониторинга станков

Расчёт к документу [2.2-E](../../2-tactics/2.2-E-cnc-monitoring.md), версия 0.2. Формула ИСЦП — общий модуль [`../4.1-A/isc.mjs`](../4.1-A/isc.mjs), срок окупаемости — [`../4.1-A/payback.mjs`](../4.1-A/payback.mjs) со сценарием E01 из [`../4.1-E/payback.csv`](../4.1-E/payback.csv); параметры кандидатов 01 и 08 — из [`../4.1-E/pilot-a.csv`](../4.1-E/pilot-a.csv).

```bash
node docs/economic-strength/data/2.2-E/model.mjs
```

Скрипт печатает шесть таблиц: цены в ₽ за станок в месяц; заявленные эффекты кейсов; эффект у клиента и r по цене подписки; срок окупаемости для команды T; ИСЦП кандидата 01 против разбора заявки 08; сверку параметров 01 с `pilot-a.csv` при цене карточки. Выборки Монте-Карло воспроизводимы: зерно фиксировано.

| Файл | Что внутри |
|---|---|
| `prices.csv` | цены 13 источников: поставщики, оценки рынка и один бюджет проекта |
| `cases.csv` | 14 кейсов: что заявлено о загрузке, простоях и производительности, кем и когда |
| `model.mjs` | нормировка цен, модель эффекта и r, срок окупаемости T по общей модели, пересчёт ИСЦП 01 |

## Паспорт: `prices.csv`

| Поле | Значение |
|---|---|
| id | `P01`…`P16` |
| название | цены систем мониторинга станков |
| единица | как у источника: `per` — за станок в месяц, в день, в год; пакет в месяц на `fleet` станков; разово за станок; бюджет проекта на `fleet` станков; `on_request` — цена по запросу; `unclear` — неясно, за что |
| частота и охват | разовый срез; Россия, Великобритания, США |
| источник | сайты поставщиков и дилеров, страницы сравнения, ComNews; ссылка — в `url` |
| дата загрузки | `accessed`, 2026-10-16 |
| уровень источника | `level`: 4 — прайс самого поставщика; 5 — оценка конкурента, обзор, пресса |
| метод | ручная выписка с HTML-страниц; нормировка — в `model.mjs`: курс ЦБ РФ на 03.10.2026 (USD 83,4839, GBP 110,299), разовые затраты делятся на 36 месяцев |
| ограничения | цены «от»; скидки за объём и НДС не учтены; P05 (MDC Master) — только из поисковой выдачи; P16 в нормировку не входит; презентация АИС «Диспетчер» — скан, не использована |

## Паспорт: `cases.csv`

| Поле | Значение |
|---|---|
| id | `C01`…`C14` |
| название | заявленные эффекты мониторинга оборудования |
| единица | `change` — относительное изменение показателя (0,31 = +31 %); `before`, `after` — доли фонда времени |
| частота и охват | 2013–2026; Россия, Великобритания, США, Индия |
| источник | CNews, ComNews, сайты поставщиков, Modern Machine Shop, Production Machining, SME, NBER/QJE |
| дата загрузки | 2026-10-16 |
| уровень источника | `level`: 3 — рецензируемая статья; 4 — заявление поставщика; 5 — пресса и отраслевые издания |
| метод | ручная выписка; `independent` = 1 — замер с контрольной группой, не от поставщика |
| ограничения | 13 из 14 кейсов — от поставщиков или прессы по их материалам; провалов не публикуют; база «до» почти нигде не названа |

## Параметры модели

Параметры эффекта — в начале раздела 3 `model.mjs`, с меткой и обоснованием в комментарии; сценарий окупаемости — строка E01 в `../4.1-E/payback.csv`; подробно — в документе, раздел 2. Экспертные оценки [Э] — уровень 6.
