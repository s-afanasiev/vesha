# 1.1-E. Коррупционная рента — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.1-E/calc-corruption.mjs
```

**Что делает скрипт:**

1. Скачивает 2 ряда Enterprise Surveys через WDI по 6 странам (Россия, Грузия, Польша, Турция, Казахстан, Малайзия): запрос взятки `IC.FRM.BRIB.ZS` и неформальные платежи `IC.FRM.CORR.ZS`; сырьё — `data/economic-strength/1.1-E/raw/`.
2. Сводит волны по странам (год × два индикатора), печатает таблицу в консоль.
3. Пишет CSV (UTF-8 с BOM, `;`).

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `firm-surveys-corruption.csv` | Страна × год: bribery incidence и неформальные платежи (2002–2025) |

**Оговорки:**
- Россия в Enterprise Surveys представлена до 2019 г. включительно (волны 2002/2005/2009/2012/2019) — после данных нет.
- Закупочные ряды (ЕИС, Счётная палата, ФАС, ВШЭ) — ручной сбор (v1), см. паспорта.
- Самоотчёты фирм недосчитывают платежи — уровни трактуются как нижний предел.
