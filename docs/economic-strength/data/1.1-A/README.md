# 1.1-A. Панель ПИИ и инвестквоты — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.1-A/calc-property.mjs
```

**Что делает скрипт:**

1. Читает список 31 страны панели из пилота 1.0-A (`../1.0-A/pilot-30-countries.csv`).
2. Скачивает 3 ряда WDI: ПИИ к ВВП (`BX.KLT.DINV.WD.GD.ZS`), ПИИ в долларах (`BX.KLT.DINV.CD.WD`), инвестквоту (`NE.GDI.TOTL.ZS`), 2010–2025 гг.; сырьё — в `data/economic-strength/1.1-A/raw/`.
3. Считает средние по окнам 2015–2019 и 2020–2024 по каждой стране, медианы панели, место России по инвестквоте, погодовой ряд ПИИ России.
4. Пишет два CSV (разделитель `;`, UTF-8 с BOM) и печатает сводку в консоль.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `panel-fdi-investment.csv` | 31 страна: ПИИ и инвестквота по двум окнам, дельты |
| `fdi-rus-2010-2025.csv` | Погодовые ПИИ России: % ВВП и млрд долл. |

**Правила и пороги:** документ `docs/economic-strength/1-foundations/1.1-A-property-rights.md`, разделы 2–3.3; паспорта — `passports.md`.

**Оговорки:**
- Страны-хабы (Швейцария, Нидерланды) имеют искажённые ПИИ из-за транзитных холдинговых потоков — при чтении панели учитывать.
- Индексы защиты собственности (IPRI, WGI) и ведомственная статистика (суды, ФССП) в v0.1 не загружены — статусы в паспортах; после их добавления скрипт дополняется расчётом корреляций «индекс → инвестиции».
