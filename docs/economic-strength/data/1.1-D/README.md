# 1.1-D. Индекс регуляторной изменчивости — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.1-D/calc-volatility.mjs
```

**Что делает скрипт:**

1. Скачивает Russian EPU (Baker–Bloom–Davis) — xlsx с `policyuncertainty.com` (лицензия CC BY 4.0), сохраняет в `data/economic-strength/1.1-D/raw/`; если локальная копия уже есть — использует её (кэш + до 4 повторов сети).
2. Разбирает xlsx без внешних библиотек: собственный zip-reader на `zlib.inflateRawSync` + разбор `sheet1.xml`/`sharedStrings.xml`.
3. Скачивает инвестиционную квоту России (WDI `NE.GDI.TOTL.ZS`, 2010–2024).
4. Считает годовые агрегаты EPU (среднее, максимум с месяцем, стандартное отклонение, число месяцев) и **ИРВ** — индекс регуляторной изменчивости (база: среднее EPU 2010–2019 ≈ 188,7 = 100), корреляции Пирсон/Спирмен с инвестквотой (одновременно и с лагом год).
5. Пишет два CSV (UTF-8 с BOM, `;`) и печатает сводку в консоль.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `epu-ru-monthly.csv` | Месячный EPU России, 1994-01 … 2026-09 (393 наблюдения) |
| `regulatory-volatility-2010-2026.csv` | Годовой ряд 2010–2026: EPU, ИРВ, инвестквота; колонки `n_laws_amend_nk` и `share_lag_lt_6m` — `NA` (ручной сбор, v1) |

**Оговорки:**
- Колонки числа поправок в НК РФ и лага <6 мес. намеренно `NA`: счёт требует ручного сбора (портал опубликования недоступен из среды).
- 2026 г. — девять месяцев (январь–сентябрь).
- Связь ИРВ и инвестиций — описательная (n = 15): малые выборки, конфаундеры 2020–2026 гг.
- Лицензия EPU: CC BY 4.0 — при перепубликации указывать Baker, Bloom & Davis («Measuring Economic Policy Uncertainty»).
