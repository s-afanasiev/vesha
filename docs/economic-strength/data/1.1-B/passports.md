# Паспорта рядов — 1.1-B «Суд как инфраструктура»

Поля — по стандарту 4.2 (п. 3.C.1). Ряды этого документа — ведомственные и институциональные; в v0.1 ни один не загружен машиной: сайты ведомств недоступны из среды агента (проверено 2026-10-18), международные индексы публикуются без API (JS-страницы и xlsx). Статусы: «не искали» / «искали, не нашли» / «данные закрыты» / «данных нет в природе».

- **`arb_forms` — Сводная статистика арбитражных судов.** Единица: число дел; распределение исходов; сроки. Частота и охват: год (по формам); Россия; 2010–2025. Источник: Судебный департамент при ВС РФ (3). Адрес: `https://www.cdep.ru/`. Метод: ручная выгрузка; сайт недоступен из среды (transport error, 2026-10-18). Ограничения: формы менялись (объединение ВАС и ВС в 2014 г.); исходы по категориям споров требуют ручной разбивки. Статус: данные существуют в природе, не загружены; ручной сбор — v1.
- **`gospors` — Споры с госорганами (налоговые, антимонопольные, таможенные).** Единица: число дел, суммы требований, доля побед. Частота и охват: год; Россия; 2010–2025. Источники: ФНС (отчётность о судебной работе), ФАС, ФТС (3). Адреса: `nalog.gov.ru`, `fas.gov.ru`, `customs.gov.ru`. Метод: ручная выгрузка; в v0.1 не выполнена. Ограничения: ведомства публикуют неполные срезы и меняют формат; суммы требований и решения по инстанциям несопоставимы без ручного сведения. Статус: не загружено; v1.
- **`uk_econ` — Экономические составы УК (159 ч. 5–7, 160, 171, 172, 198, 199 и др.).** Единица: число дел по стадиям (возбуждено / дошло до суда / прекращено / оправдано). Частота и охват: год (формы № 10-а, № 1); Россия; 2010–2025. Источник: Судебный департамент (3), `cdep.ru`. Метод: ручная выгрузка; недоступно из среды. Ограничения: учёт по статьям менялся; прекращение на этапе следствия в судебной статистике не видно (нужна статистика МВД/СК — отдельный источник). Статус: не загружено; v1.
- **`mkas` — МКАС при ТПП РФ.** Единица: число дел, суммы, исходы. Частота: год; 2010–2025. Источник: отчёты МКАС (3), `tpprf.ru`. Метод: ручная выгрузка (PDF); не выполнена. Ограничения: добровольная отчётность; состав спорящих сторон раскрывается частично. Статус: `искали, не нашли` машиночитаемого ряда; v1.
- **`rac` — Российский арбитражный центр и другие внутренние третейские учреждения.** Единица: число дел. Частота: год; 2017–2025. Источники: отчёты РАЦ при РСПП, АЦ при РСПП (3). Метод: ручной сбор; не выполнен. Ограничения: после реформы третейского разбирательства (2016) число постоянно действующих учреждений резко сокращено; сводной статистики нет. Статус: фрагменты; сводного ряда нет в природе; v1.
- **`sip` — Суд по интеллектуальным правам (СИП).** Единица: число дел, исходы, сроки. Частота: год; 2013–2025. Источник: Судебный департамент / сайт СИП (3). Метод: ручная выгрузка; не выполнена. Ограничения: отдельной формы нет — собирается по категориям. Статус: не загружено; v1.
- **`wjp_rol` — WJP Rule of Law Index.** Единица: балл 0–1 по факторам (в т.ч. гражданское и уголовное правосудие). Частота: год; 140+ стран; до 2025. Источник: World Justice Project (3). Адрес: `https://worldjusticeproject.org/rule-of-law-index/`. Метод: ручная выгрузка; страницы отдаются JS-приложением (проверено 2026-10-18) — прямой скрейпинг невозможен. Ограничения: экспертно-опросный композит; по России публикация с 2022 г. ограничена. Статус: `искали, не нашли` машиночитаемого доступа; возможна ручная выгрузка xlsx — v1.
- **`ipp_spb` — Исследования Института проблем правоприменения (ЕУСПб).** Единица: обзоры и оценки (академические). Частота: нерегулярно; 2010–2025. Источник: ЕУСПб (3). Адрес: `https://enforce.spb.ru/`. Метод: ручной обзор публикаций; в v0.1 не выполнялся. Ограничения: оценки не образуют рядов; используются как качественная опора. Статус: `не искали` систематически; v1.
- **`vs_reviews` — Обзоры судебной практики ВС РФ.** Единица: число обзоров и разъяснений (плюс предмет). Частота: несколько в год; 2014–2025. Источник: ВС РФ (3), `vsrf.ru`. Метод: ручной сбор перечня; в v0.1 не выполнялся. Ограничения: сам по себе счёт обзоров не измеряет единообразие — нужен дизайн оценки (см. 3.2). Статус: не загружено; v1.
