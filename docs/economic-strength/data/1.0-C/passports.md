# Паспорта рядов — 1.0-C «Источники роста российской экономики в 2000–2025 гг.»

Поля — по стандарту 4.2 (п. 3.C.1). Все ряды WDI загружены 2026-10-18 (винтаж 2026-10-08), уровень источника 2, лицензия CC BY 4.0, если не отмечено иначе. Страны сравнения: Россия, Польша, Турция, Казахстан, Малайзия (вопрос 3).

- **`gdp_real` — ВВП в постоянных ценах.** Единица: постоянные национальные валюты (масштаб — по метаданным API). Частота и охват: год; 5 стран; 1995–2025. Источник: WDI `NY.GDP.MKTP.KN` (2). Адрес: `https://api.worldbank.org/v2/country/{iso3}/indicator/NY.GDP.MKTP.KN`. Метод: напрямую. Ограничения: пересмотры базового года; для роста в постоянных долларах ряд не использован из-за неполного покрытия. Версия: релиз 2026-10-08.
- **`investment_real` — Валовое накопление основного капитала (инвестиции).** Единица: постоянные национальные валюты. Частота и охват: год; 5 стран; 1995–2025. Источник: WDI `NE.GDI.FTOT.KN` (2). Адрес: `https://api.worldbank.org/v2/country/{iso3}/indicator/NE.GDI.FTOT.KN`. Метод: напрямую. Ограничения: альтернативный агрегат `NE.GDI.TOTL.KN` у Турции пуст (проверено 2026-10-18); для капитального запаса скрипт строит перпетуальный запас (допущения — в документе, раздел 2). Версия: релиз 2026-10-08.
- **`labor_force` — Рабочая сила.** Единица: млн чел. Частота и охват: год; 5 стран; 1990–2024. Источник: WDI `SL.TLF.TOTL.IN` (2, модельная оценка МОТ). Адрес: `https://api.worldbank.org/v2/country/{iso3}/indicator/SL.TLF.TOTL.IN`. Метод: напрямую. Ограничения: модельная оценка; не отражает отработанные часы и качество труда (часть вклада уходит в TFP-остаток). Версия: релиз 2026-10-08.
- **`pop_1564` — Население 15–64 лет.** Единица: млн чел. Частота и охват: год; 5 стран (для сценариев — Россия); 1960–2024. Источник: WDI `SP.POP.1564.TO` (2). Адрес: `https://api.worldbank.org/v2/country/{iso3}/indicator/SP.POP.1564.TO`. Метод: напрямую. Ограничения: демографические пересмотры; прогнозы WDI не содержат — сценарии строятся экстраполяцией тренда. Версия: релиз 2026-10-08.
- **`va_agr` — ВДС сельского хозяйства.** Единица: постоянные долл. США. Частота: год; Россия; 1995–2024. Источник: WDI `NV.AGR.TOTL.KD` (2). Адрес: `https://api.worldbank.org/v2/country/RUS/indicator/NV.AGR.TOTL.KD`. Метод: напрямую. Ограничения: только укрупнённый сектор — отраслевой разрез требует KLEMS (паспорт `tfp_klems`). Версия: релиз 2026-10-08.
- **`va_manf` — ВДС обрабатывающей промышленности.** Единица: постоянные долл. США. Частота: год; Россия; 1995–2024. Источник: WDI `NV.IND.MANF.KD` (2). Адрес: `https://api.worldbank.org/v2/country/RUS/indicator/NV.IND.MANF.KD`. Метод: напрямую. Ограничения: укрупнённый сектор; ревизии при пересмотрах ОКВЭД. Версия: релиз 2026-10-08.
- **`tfp_klems` — СФП по отраслям (Russia KLEMS).** Единица: индекс. Частота: год; Россия; до 2020 г. Источник: НИУ ВШЭ, Russia KLEMS (3). Адрес: `https://www.hse.ru/klems`. Метод: ручная загрузка файла (в v0.1 не выполнялась). Ограничения: `искали, не нашли` простого API; ряд заканчивается 2020 г. — после разрыв. Версия: последний релиз. Условия: академическая с указанием.
- **`tfp_ted` — СФП (Conference Board TED).** Единица: индекс. Частота: год; Россия; до 2023–2024. Источник: Conference Board, Total Economy Database (3). Адрес: `https://www.conference-board.org/data/economydatabase/`. Метод: ручная выгрузка через портал (в v0.1 не выполнялась). Ограничения: интерактивный портал без открытого API; условия использования ограничивают перепубликацию. Версия: TED (последний релиз). Условия: бесплатно с регистрацией, перепубликация ограничена.
