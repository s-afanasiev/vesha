# 1.0-C. Декомпозиция роста России 2000–2025 — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.0-C/calc-growth.mjs
```

**Что делает скрипт:**

1. Скачивает 6 рядов WDI (Всемирный банк) по 5 странам (Россия, Польша, Турция, Казахстан, Малайзия), 1990–2025 гг.; сырые ответы API сохраняет в `data/economic-strength/1.0-C/raw/` с датой загрузки в имени файла.
2. Строит перпетуальный запас капитала (δ = 5 %/год, K(2000) = 2,5 × ВВП(2000)) и считает декомпозицию Солоу по 4 периодам: 2000–2008, 2009–2013, 2014–2021, 2022–последний полный год страны (Россия — 2025, Казахстан — 2024).
3. Считает укрупнённый отраслевой разрез России (сельское хозяйство, обрабатывающая промышленность, ВВП) — вместо недоступных KLEMS.
4. Считает TFP России при доле капитала α ∈ {0,35; 0,40; 0,45} (устойчивость).
5. Симулирует 3 сценария 2026–2035 гг. (инерционный, капиталоёмкий +5 п.п. нормы накопления, производительностный TFP +2 п.п./год) с затухающей отдачей капитала и чувствительность к начальному K/Y.
6. Пишет 5 CSV (разделитель `;`, кодировка UTF-8 с BOM) и печатает краткий отчёт в консоль, включая контроль тождества «сумма вкладов = темп роста».

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `growth-decomposition-2000-2025.csv` | 5 стран × 4 периода: рост ВВП и вклады капитала, труда, TFP (п.п./год), норма накопления |
| `sector-growth-rus.csv` | рост укрупнённых секторов России по периодам |
| `tfp-sensitivity.csv` | TFP России при α = 0,35 / 0,40 / 0,45 |
| `potential-growth-scenarios.csv` | 3 сценария 2026–2035: gK, gL, TFP, потенциальный рост ВВП, допущения |
| `potential-sensitivity.csv` | потенциальный рост при K/Y ∈ {2,5; модельный; 3,5; 4,0} × TFP ∈ {0; +2 п.п.} |

**Правила и пороги:** методика — `docs/economic-strength/1-foundations/1.0-C-growth-accounting.md`, раздел 2; паспорта рядов — `passports.md` в этой папке.

**Исключения и оговорки:**
- Ряд обрабатывающей промышленности начинается с 2002 г. — период 2000–2008 для него не считается (NA).
- У Турции агрегат `NE.GDI.TOTL.KN` пуст в WDI; используется `NE.GDI.FTOT.KN` (проверено 2026-10-18).
- Качество труда (Q_L) не выделено — его вклад остаётся в TFP; KLEMS и TED не загружены (v1).
- Сценарии — не прогноз: коридоры чувствительности при фиксированных допущениях.
- Все допущения (δ, K/Y, α, тренд труда) зафиксированы в скрипте и описаны в документе.
