# Данные документа 4.1-A — формула ИСЦП v0.2 и пилот

Расчёт к документу [4.1-A](../../4-method/4.1-A-isc-formula.md).

```bash
node docs/economic-strength/data/4.1-A/score.mjs
```

Флаг `--theta 6` меняет порог квадрантов (по умолчанию 5). Выборки Монте-Карло воспроизводимы: зерно фиксировано.

## Файлы

| Файл | Что внутри |
|---|---|
| `products.csv` | 20 продуктов пилота: код, название, класс, свой ли продукт (`own`), есть ли полевой замер (`measured`), описание. Это всё, что видит оценщик до оценки |
| `pilot-a.csv` | параметры группы A с обоснованием в `note` |
| `pilot-b.csv` | параметры группы B — появится после слепой оценки (документ 4.1-A, 4.4); группе B до сдачи нельзя открывать `pilot-a.csv` и `results-a.csv` |
| `payback.mjs` | общая модель срока окупаемости для команды T — помесячный денежный поток; ей пользуются 4.1-E (`t-model.mjs`) и 2.2-E (`model.mjs`) |
| `score.mjs` | формула v0.2: баллы из параметров, свёртка, квадранты, Монте-Карло; если есть `pilot-b.csv`, считает согласие групп |
| `results-a.csv` | выход скрипта по группе A: баллы, V, V по формуле v0.1 (`V01`), R, ИСЦП при α = 0,6 и 0,4, Δ, квадранты v0.2 и v0.1, 80-процентный интервал, устойчивость квадранта |

## Паспорт параметров

Параметры — экспертные оценки [Э], не статистические ряды; уровень источника — 6 (стандарт 4.2, 3.C.2).

| Столбец | Что означает | Единица |
|---|---|---|
| `g2`, `g3`, `g4` | стоп-фильтры: эффект измерим; нет перевешивающего вреда; реализуемо по праву | 1 или 0 |
| `r_min`, `r_mode`, `r_max` | годовой эффект у клиента ÷ его годовая стоимость владения, третий год | отношение |
| `rho` | доля эффекта, отнятая у других участников рынка; больше 0,5 → G1 = 0 | 0…1 |
| `s` | доля импортных решений в инсталлированной базе сегмента | 0…1 |
| `c` | критичность сегмента | 0; 0,3; 0,6; 1 |
| `d` | независимость самого продукта | 0; 0,5; 1 |
| `x` | экспортный потенциал | 0…10, шаги 0/3/6/10 |
| `q_min`, `q_mode`, `q_max` | эффект у всех клиентов на целевом масштабе ÷ годовая стоимость команды | отношение |
| `time`, `capital`, `cert`, `expertise`, `competition` | слагаемые сложности входа | баллы по таблице 3.3 документа |
| `t_min`, `t_mode`, `t_max` | срок окупаемости для команды | месяцы |
| `note` | обоснование оценщика | текст |
