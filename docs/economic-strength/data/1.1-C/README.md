# 1.1-C. Патенты и НИОКР — README

**Команда запуска** (из корня репозитория; Node ≥ 20; нужен доступ к сети):

```
node docs/economic-strength/data/1.1-C/calc-ip.mjs
```

**Что делает скрипт:**

1. Скачивает 4 ряда WDI по 5 странам (Россия, Япония, Корея, Китай, Польша), 1980–2025 гг.: заявки резидентов (`IP.PAT.RESD`), заявки нерезидентов (`IP.PAT.NRES`), НИОКР (% ВВП, `GB.XPD.RSDV.GD.ZS`), исследователи на млн (`SP.POP.SCIE.RD.P6`). Сырьё — `data/economic-strength/1.1-C/raw/`.
2. Считает уровни 2000/2010/последний год, среднегодовые темпы заявок резидентов (2000–2010 и 2010–последний), последние НИОКР и исследователей.
3. Пишет два CSV (UTF-8 с BOM, `;`) и печатает сводку в консоль.

**Выходные файлы (в этой папке):**

| Файл | Содержание |
|---|---|
| `patents-rus.csv` | Погодовые заявки России: резиденты и нерезиденты |
| `ip-panel.csv` | 5 стран: заявки (уровни и темпы), НИОКР, исследователи |

**Оговорки:**
- Заявки — метрика усилий/отчётности, не полезности: доля действующих и лицензируемых патентов — ФИПС вручную (v1).
- Данные WDI по патентам обновлены до 2024 г., НИОКР — до 2023–2024 гг.
- Нормативный слой (параллельный импорт, постановление № 299, ст. 1261/1280 ГК) — качественный разбор в документе.
