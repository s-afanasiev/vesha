# 4.1-E/03. Нормоконтроль чертежей по ЕСКД вне САПР

**Что это.** Проверка чертежей и спецификаций в PDF и DXF на соответствие ЕСКД до передачи в производство: правила для оформления, языковая модель — для текста технических требований.

## 6. Выводы — что делать

- **Ценность высокая, реализуемость — на границе** (R 4,83): долгий цикл продажи и конкуренция внутри экосистем САПР.
- **Что есть на рынке [Ф]:**
  - пакетный нормоконтроль в nanoCAD 25;
  - MechaniCS — надстройка над AutoCAD, развивается с 2001 г.;
  - Dracon Draw — строит КД по ЕСКД из STEP и машинно проверяет оформление; 100–1600 ₽ за лист, внедрение на предприятии от 300 тыс. ₽, версия 0.1.0;
  - Normacs — проверяет актуальность стандартов, на которые ссылается чертёж.
- **Для разработчика.** Ядро MVP:
  1. Разбор PDF и DXF: рамка, основная надпись, размеры, текст технических требований.
  2. Набор правил ЕСКД с номерами пунктов ГОСТ (2.104, 2.109, 2.307, 2.316 …).
  3. Отчёт замечаний с координатами на листе.

  Риск — закрытые форматы КОМПАС: работать через экспорт или API КОМПАС. Без нормоконтролёра-партнёра правила не собрать.
