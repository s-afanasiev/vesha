## Контекст

Vesha — тонкий Express + статика, каталог экспериментов `/experiments/`. Фокус — **idea-radar** («Радар идей»): опрашиваем открытые ленты Курской области, склеиваем перепечатки в сюжеты, доставляем тексты госактов, размечаем сдвиги через LLM. Формула продукта: **идея = сдвиг × боль (pain-radar) × человек (анкета)**. pain-radar пока мок без бэкенда.

## Решения, которые нельзя переиграть случайно

- **Ключи LLM не зашиваем в env** — llm-picker на фронте (ключ/модель/адрес), env — только опциональный дефолт. Баланс — честный отказ для провайдеров без API баланса.
- **Служебные ручки радара — только админ** (решение 10.10.2026): `polls | stories | gov-texts | mark` за `requireAdmin`, в UI — part `ops`. Скрытие в UI — удобство, граница — на сервере. Открывать гостям — только с отдельной квотой на батч: сейчас guard считает батч разметки (до 20 вызовов LLM) одним запросом.
- **Доставка текстов не в таймере** (решение 02.10.2026: если включать — раз в сутки максимум).
- **Направление сдвига — на связи** «сдвиг × адресат-ниша» (И3), не колонка сдвига.
- **Полная пересборка сюжетов запрещена**, когда есть сдвиги или журнал разметки — только `attach` новых публикаций (каскадное удаление стёрло бы разметку).
- Шум (рубрики → `off_topic`, правило `relevance.js`) идёт мимо счётчика и фильтра ниши; шумовые сюжеты в метриках И8 не участвуют (`model = 'noise-rule'`).
