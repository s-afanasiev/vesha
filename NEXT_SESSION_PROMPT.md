## Контекст

Vesha — тонкий Express + статика, каталог экспериментов `/experiments/`. Фокус — **idea-radar** («Радар идей»): опрашиваем открытые ленты Курской области, склеиваем перепечатки в сюжеты, доставляем тексты госактов, размечаем сдвиги через LLM. Формула продукта: **идея = сдвиг × боль (pain-radar) × человек (анкета)**. pain-radar пока мок без бэкенда.

## Ближайшие шаги (по порядку)

1. **Первый настоящий прогон разметки.** Ключ Gemini из `.env` невалиден («API key not valid»). Вставить рабочий ключ в блок «Нейросеть» на `/experiments/idea-radar/` (или обновить `GEMINI_API_KEY`) → «Разметить 5 сюжетов». Ожидание: сдвиги в `idea_radar_shifts` + адресаты, предметы в `idea_radar_subjects`, метрики оживают. Оценить качество промпта v1, при необходимости — правка промпта (поднять `PROMPT_VERSION` в `marking.js`, тогда сюжеты переразмечаются).
2. **precision@30 — последний кусок И8.** Ревью-UI «верно/неверно» для выборки сдвигов, таблица вердиктов, precision в `GET /metrics` (сейчас `precisionReview: null`).
3. **`RankShifts` + `idea_radar_weekly`** — матпредставление «неделя × предмет/тип × ниша × регион × вид источника»; чистое действие по образцу `RankPains` (pain-radar-review Б7), материализовать, когда накопится разметка.
4. **Карта перемен и календарь сроков** — UI фазы 2 поверх сдвигов (эффективные даты, стадии по видам источников).
5. Позже: И5 (роли источников local_signal/lead_indicator), И6 (независимые источники по видам мира), И7 (спрос Вордстат + предложение через каркас), ступень 2 каркаса (карточный контракт, `collector_items`) — вместе с pain-radar фазой 2.

## Решения, которые нельзя переиграть случайно

- **Ключи LLM не зашиваем в env** — llm-picker на фронте (ключ/модель/адрес), env — только опциональный дефолт. Баланс — честный отказ для провайдеров без API баланса.
- **Доставка текстов не в таймере** (решение 02.10.2026: если включать — раз в сутки максимум).
- **Направление сдвига — на связи** «сдвиг × адресат-ниша» (И3), не колонка сдвига.
- **Полная пересборка сюжетов запрещена**, когда есть сдвиги или журнал разметки — только `attach` новых публикаций (каскадное удаление стёрло бы разметку).
- Шум (рубрики → `off_topic`, правило `relevance.js`) идёт мимо счётчика и фильтра ниши; шумовые сюжеты в метриках И8 не участвуют (`model = 'noise-rule'`).

## Как запускать и проверять

- Тесты: `npm test` (40, все зелёные — прогонять перед «готово»).
- Сервер: `npm start` (порт 3000), миграции накатываются при старте; БД — локальный Postgres 15 `localhost:5432` (без pgvector; pg_trgm доступен, сознательно не включён — см. И10).
- Дашборд: `/experiments/idea-radar/`. Ручки: `POST /api/idea-radar/polls | stories | gov-texts | mark`, `GET /api/idea-radar/sources | metrics | keywords | publications | disk`.
- Живой smoke: `node main.js` в фоне + fetch-скрипт; сервер останавливать после проверки. Внешние источники — только через ручки, не из тестов.
- Стиль правок: канон `docs/oop-principles.md` (метки П…), доменные слова не протекают в каркас `collectors/` (греп-тест), числа поведения — в `config.js`/декларации, коммиты после каждой логической партии.
